## 한 줄 정의

**마블로(Marblo)** 는 여러 AI 코딩 에이전트를 하나의 칸반 보드에서 **동시에 오케스트레이션**하는 데스크톱 앱입니다. 중앙 오케스트레이터가 태스크를 나눠 각 에이전트에 할당하고, 진행 상황을 실시간으로 추적합니다. macOS와 Windows에서 실행됩니다.

Cursor나 Copilot이 에이전트 한 명을 붙여 준다면, 마블로는 **에이전트 군단**을 운용합니다.

## 핵심 구성 요소

- **이종 에이전트**: Claude, GPT/Codex, Antigravity를 동시에 굴립니다. 각 모델의 강점에 맞춰 백엔드·프론트엔드·테스트 등 역할을 나눠 배치합니다.
- **중앙 오케스트레이터**: 태스크를 분할하고 에이전트에 할당하며, 의존성과 순서를 관리합니다.
- **칸반 보드**: TODO → IN_PROGRESS → REVIEW → DONE. 각 에이전트가 지금 뭘 하는지 한 화면에서 봅니다.
- **MCP 네이티브**: Model Context Protocol을 기본 지원해, 파일·DB·API 같은 도구를 여러 에이전트가 공유합니다.
- **로컬 실행**: 모든 에이전트가 사용자 머신에서 돌아갑니다. 코드가 외부 서버로 나가지 않습니다.

## 비용 구조 — BYO 모델

각 에이전트는 **사용자 본인의 API 키 또는 구독**으로 실행됩니다(Claude → Anthropic, GPT/Codex → OpenAI 등). 마블로 구독료는 이 에이전트들을 통합 지휘하는 **오케스트레이션 비용**이며, AI 사용료를 포함하지 않습니다. Free 플랜은 월 ₩0, Pro는 월 ₩19,000입니다.
