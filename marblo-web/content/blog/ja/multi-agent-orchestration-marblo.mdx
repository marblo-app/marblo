## エージェント 1 人 vs 軍団

多くの AI コーディングツールはエージェントを 1 人だけ提供します。1 つの作業を素早く片づけるには良いですが、規模が大きくなるとボトルネックになります。**複数のエージェントを同時に**動かせば、独立した作業を並列で進められます — ただし、誰が何をしているかを制御する手段が必要です。

## Marblo のアプローチ

Marblo では**中央オーケストレーター**が異種 AI エージェント(Claude、GPT/Codex、Antigravity)を物理的・論理的に分割し、タスクを割り当てます。各モデルの強みに合わせて役割を配置します。

- **Claude** — バックエンド実装
- **GPT/Codex** — フロントエンド
- **Antigravity** — テスト

## カンバンで見る進捗

複数のエージェントが同時に動くと、「今何が進んでいるのか」が見えにくくなりがちです。Marblo は作業を**カンバンボード**(TODO → IN_PROGRESS → REVIEW → DONE)で可視化し、各エージェントの状態・割り当てタスク・完了状況をリアルタイムで追跡します。

## ローカル実行と MCP

すべてのエージェントはユーザーのマシン上でローカルに実行され、**MCP をネイティブ対応**して同じツール・コンテキストを共有します。各モデルはユーザー自身の API キーまたはサブスクリプションで動くため、Marblo はオーケストレーション層に集中します。

## まとめ

オーケストレーションの要点は「たくさん動かすこと」ではなく「たくさん動かしても制御可能な状態を保つこと」です。中央調整 + カンバンの可視性 + ローカル実行がその三角形を形づくります。
