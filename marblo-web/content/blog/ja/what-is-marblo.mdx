## 一行の定義

**Marblo(マブロ)** は、複数の AI コーディングエージェントを一つのカンバンボードで**同時にオーケストレーション**するデスクトップアプリです。中央オーケストレーターがタスクを分割して各エージェントに割り当て、進捗をリアルタイムで追跡します。macOS と Windows で動作します。

Cursor や Copilot がエージェントを 1 人提供するのに対し、Marblo は**エージェントの軍団**を運用します。

## 主要な構成要素

- **異種エージェント**: Claude、GPT/Codex、Antigravity を同時に動かします。各モデルの強みに合わせてバックエンド・フロントエンド・テストなどの役割を分担します。
- **中央オーケストレーター**: タスクを分割してエージェントに割り当て、依存関係と順序を管理します。
- **カンバンボード**: TODO → IN_PROGRESS → REVIEW → DONE。各エージェントが今何をしているかを一画面で確認できます。
- **MCP ネイティブ**: Model Context Protocol を標準対応し、ファイル・DB・API などのツールを複数のエージェントで共有します。
- **ローカル実行**: すべてのエージェントがユーザーのマシン上で動きます。コードが外部サーバーに送信されることはありません。

## コスト構造 — BYO モデル

各エージェントは**ユーザー自身の API キーまたはサブスクリプション**で実行されます(Claude → Anthropic、GPT/Codex → OpenAI など)。Marblo のサブスクリプション料金はこれらのエージェントを統合指揮する**オーケストレーション費用**であり、AI 利用料は含みません。Free プランは月額 ₩0、Pro は月額 ₩19,000 です。
