# Marblo v3.0.1 — 배포 전 수동 스모크 가이드

> 목적: 배포본(공증/서명된 dmg·exe)이 **실제로 설치·실행되고, 이번 릴리스의 3개 핵심 수정이 동작**하는지 사람 손으로 최종 확인.
> 자동으로 끝난 것: Gatekeeper(공증) 통과 ✅ / 앱 런치·렌더러 부팅 ✅ (헤드리스 검증 완료). **아래는 화면을 봐야 하는 부분만.**
> 소요: Mac 약 3분 + Windows 약 3분.

---

## A. Mac (Apple Silicon 전용) — 약 3분

> ⚠️ 이 빌드는 **arm64(Apple Silicon) 전용**입니다. Intel Mac에서는 실행되지 않습니다. (universal 빌드는 fast-follow 티켓 `tozEVh4hwcunE8Rsu90K`)

### 0) 다운로드 & 설치

1. https://marblo.app/download → **Mac 다운로드** 클릭 → `Marblo-3.0.1-arm64.dmg`
2. dmg 열기 → `Marblo.app`을 **Applications**로 드래그
3. 실행. Gatekeeper 경고가 **뜨지 않아야 정상**(공증됨). 뜬다면 캡처해서 공유.

### 1) 로그인 (Firebase auth) — ⭐ Firebase 설정 임베드 확인

> 배경: v3.0.1 로컬 빌드가 `.env.production` **플레이스홀더**(`your-api-key`)를 임베드해
> `onAuthStateChanged` 미발화 → **무한 로딩 스피너**로 전 Mac 베타 유저 차단됨.
> "런치만" 검증하면 못 잡는다 — **반드시 화면이 로그인 폼까지 도달하는지** 눈으로 확인.

- [ ] 앱이 정상적으로 창을 띄운다
- [ ] 화면이 비어 있거나 흰 화면으로 멈추지 않는다. 특히 `v3/electron/preload.ts` 변경 PR이면 패키지 `.app` 실기동으로 `window.electronAPI`가 노출되는지 확인한다.
- [ ] 언어 선택 후 **무한 로딩 스피너에 갇히지 않는다** (스피너가 10초 넘게 계속이면 실패)
- [ ] **로그인 화면(폼)이 실제로 뜬다** — 여기 도달 = Firebase 설정 임베드 정상
- [ ] Google/이메일 로그인 성공 → 프로젝트 열기 화면 진입
- ❗ 무한 스피너 또는 "연결할 수 없습니다" 에러 화면 → **Firebase 설정 임베드 실패**(플레이스홀더/누락) 신호 → 즉시 공유하고 배포 중단
- 참고: 빌드 자체는 `check-firebase-env.mjs` 가드가 플레이스홀더면 `npm run build` 를 실패시킨다. 이 스모크는 최종 산출물에서 육안 재확인.

### 2) #277 — 파일트리에 `.env` 노출되는지

- [ ] 프로젝트 열기 → 좌측 파일트리
- [ ] `.env` / `.env.example` 등 **env 파일이 보인다** (이전엔 닷파일 통째 숨김이라 안 보였음)
- [ ] 그 외 일반 닷파일(`.DS_Store` 등)은 여전히 숨김 (gitignore 존중)

### 3) #278 — 코드에디터 Cmd+S 저장 유지 (⭐가장 중요, 데이터 유실 수정)

- [ ] 파일 A 열기 → 내용 수정 → **Cmd+S**
- [ ] **파일 B로 전환** → 다시 **파일 A로 전환**
- [ ] 파일 A의 수정 내용이 **그대로 남아있다** (예전 버그: 다른 파일로 갔다 오면 저장이 날아감)
- [ ] 앱을 **완전 종료 후 재실행** → 파일 A 수정 내용 **디스크에 저장되어 있음**
- ❗ 이게 실패하면 배포 중단 — 크리티컬 회귀

### 4) #276 — 워크트리 열어도 오케스트레이터 세션 안 끊김

- [ ] 보드에서 오케스트레이터 세션 켠 상태
- [ ] 워크트리 열람/전환 실행
- [ ] 오케스트레이터 세션이 **강제 종료되지 않고 유지**된다 (터미널 대화 컨텍스트 살아있음)

### 5) 마무리

- [ ] 앱 정상 종료 (크래시·행 없음)

## B. Windows — 약 3분

> EV 서명(KoreaSSL) 되어 있어 SmartScreen은 대부분 바로 통과. 그래도 "알 수 없는 게시자" 경고가 뜨면 캡처 공유.

### 0) 다운로드 & 설치

1. https://marblo.app/download → **Windows 다운로드** 클릭 → `Marblo-Setup-3.0.1.exe`
2. 실행. SmartScreen 경고가 **뜨지 않아야 정상**(EV 서명). 뜨면 `추가 정보 → 실행`.
3. NSIS 설치 진행 → 완료 후 실행

### 1~4) 기능 확인

- Mac의 1~4번과 **동일 체크리스트** 수행 (로그인 / #277 .env 노출 / #278 Cmd+S 유지 / #276 워크트리)
- Windows 고유 확인:
  - [ ] 설치/실행 시 경로·권한 문제 없음
  - [ ] 자동 업데이트 피드(`latest.yml`) 정상 (선택: 다음 핫픽스 때 검증)
