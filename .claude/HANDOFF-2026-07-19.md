## ★반드시 지킬 작업 규칙 (오늘 사고로 얻은 것)

1. **라이브 체크아웃에서 git 조작 금지.**
   `npm run dev` 가 `tsc -p electron/tsconfig.json --watch` 로 `v3/electron/**/*.ts` 를 감시한다.
   라이브 체크아웃에서 `checkout`/`merge`/`reset`/`pull` 을 하면 그 파일들이 다시 쓰이고 →
   `dist-electron` 재빌드 → **앱 재시작 → 라이브 오케와 사장님 작업이 끊긴다.**
   오늘 내가 이걸 몰라서 여러 번 끊었고, 애꿎은 에이전트를 원인으로 지목해 2기를 잘못 정지시켰다.

2. **검증은 격리 워크트리에서.**
   `git worktree add --detach /tmp/marblo-vNNN origin/<branch>` → 그 안에서 tsc/vitest.
   `node_modules` 는 라이브 것에 symlink 하면 된다.

3. **머지는 앱을 안 끊는다.**
   `gh pr merge` 는 GitHub 원격에서만 일어난다. 라이브 체크아웃은 `git pull` 해야 바뀐다.
   → 머지는 자유롭게, **`git pull` 은 사장님이 재시작을 원할 때만.**

4. **재빌드/재시작은 반드시 사장님 승인.** 라이브 오케를 죽인다.

5. **완료 보고는 실제 커밋된 파일 + 실제 돌린 테스트 출력에만 근거.**
   오늘 한 에이전트가 "구현 완료, 테스트 186건 통과" 로 보고했는데 코드가 레포 어디에도 없었다.

## 충돌 해소 요령 (오늘 #500 에서 쓴 방법)

에이전트가 완료 보고를 낸 뒤 내가 다른 PR 을 머지하면 충돌이 난다. 그때:
격리 워크트리(`git worktree add /tmp/... -b fix/NNN origin/<branch>`) → `git merge origin/main`
→ 충돌 해소 → tsc + 전체 vitest(기준선 대조) → `git push origin HEAD:<원브랜치>` → 머지.
라이브 체크아웃은 여전히 무접촉이라 앱이 안 끊긴다.

## ★맥북에서 할 작업 — 오케 세션 이식성 (2026-07-19 조사 완료, 티켓 미생성)

사장님 질문 "기기 바꾸면 오케 세션이 안 따라간다, 고칠 수 있나" 조사 결과.

**왜 안 따라가나 — 구조적 한계 2겹**
1. 저장 위치가 **절대경로 인코딩**이다. `orchestrator-manager.ts:1485` 의 `getOrchStorePath()` 가
   `~/.claude/projects/<encodeClaudeProjectDir(rootPath)>/marblo-orch-sessions.json` 을 쓴다.
   맥북은 사용자명·경로가 달라 **다른 디렉터리를 본다** — 파일을 복사해도 이름이 안 맞는다.
2. **sessionId 는 포인터일 뿐 실체가 아니다.** 대화 내용은 CLI 로컬에 있고 `~/.claude/projects` 만 **650MB**.
   이걸 안 옮기면 `resume <id>` 가 "모르는 세션" 이 되고,
   **codex 는 그때 새로 만들지 않고 즉사한다** (계약: codex_resume_contract_unknown_id_kills, #496 관련).

### 작업 1 — codex 세션 저장소를 영속 경로로 ★우선
현재 `$TMPDIR/marblo-agent-configs/codex-home-*`. **macOS 가 주기적으로 지우는 임시 디렉터리**라
기기를 안 바꿔도 오케 codex 세션이 통째로 사라질 수 있다. `~/.marblo` 하위 영속 경로로 이전.
작고 명확하며, 기기 이전과 무관하게 지금도 손해를 보고 있다.

### 작업 2 — 오케 세션 **메타**만 기기 간 동기화 (트랜스크립트 제외)
**#494(텔레그램 채널 메타 동기화, 토큰 제외) 패턴을 그대로 재사용**하면 된다.
- 프로젝트별 오케 모델 연속성(claude/codex 중 무엇을 쓰던 프로젝트인지) — cf [[orchestrator-model-continuity]], #496
- 작업 컨텍스트는 **이미 Firestore 에 있다**(티켓·액티비티). 이 인수인계 문서 자체가 그걸로 만들어졌다
→ "대화 자체" 는 못 옮겨도 "어디까지 했고 뭘 하던 프로젝트인지" 는 옮길 수 있다. 가치의 대부분이 여기 있다.

### 하지 말 것 — 트랜스크립트 완전 이식
650MB 동기화 + 절대경로 키 정규화가 필요하다. 비용 대비 효용이 낮아 **권하지 않는다** (조사 결론).
