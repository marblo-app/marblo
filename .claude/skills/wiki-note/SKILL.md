# /wiki-note

루트는 항상 `docs/wiki`. 원본(`v3/docs`, `docs/lectures` 등)은 P1 — 한 글자도 고치지 않는다.

## 목적

링크를 안 따라가도 판정·핵심수치·왜·한계가 회수되는 노트 한 장.

## 입력

| 항목        | 필수                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------- |
| 한 줄 주장  | ✅ 한 노트 = 한 주장                                                                      |
| 원본 경로   | ✅                                                                                        |
| 종류(kind)  | ✅ `knowledge`(지금 참인 사실·값·절차) 또는 `archive`(조사·실험·판정 기록) — 아래 4a 참조 |
| 폴더        | ⬜ 없으면 슬롯 표로 제안                                                                  |
| 판정        | ⬜ adopt / no-go / observe / undecidable (`archive`에서만 씀)                             |
| 개정 슬러그 | ⬜ 있으면 개정 모드                                                                       |

## 단계 (게이트를 빼지 말 것)

| #   | 단계                                                                                                                                                                                     | 게이트                                                                                                                               |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 원본 정독                                                                                                                                                                                | 원본 수정 금지                                                                                                                       |
| 2   | `_meta/do-not-retry.md` 검색                                                                                                                                                             | 히트 시 사유코드·해금 조건을 제시                                                                                                    |
| 3   | ASCII kebab-case 슬러그, 전역 유일                                                                                                                                                       | 중복이면 중단                                                                                                                        |
| 4   | frontmatter 5필드 순서 고정, 태그는 사전만                                                                                                                                               | 없는 태그는 TAXONOMY 먼저                                                                                                            |
| 4a  | 종류(kind) 하나를 고르고 태그에 `kind/knowledge` 또는 `kind/archive`를 넣는다. **건너뛰지 않는다** — [[LINT]]의 CI 게이트가 새 노트의 미분류를 에러로 막는다                             | 둘 다이거나 없으면 되돌아감. 판단 기준: 지금 무엇이 참인지 남을 사실 한 장이면 `knowledge`, 특정 시점의 조사·실험 기록이면 `archive` |
| 5   | 표준 섹션 — **4a에서 고른 종류에 따라 다르다:** `knowledge`는 첫 섹션이 `## 지금 무엇이 참인가`(사실부터, 판정문으로 열지 않는다). `archive`는 6~9(R1~R4)의 질문→판정 순서를 그대로 쓴다 | `knowledge`에 `## 한 줄 판정`·`## 무엇을 물었나` 헤딩을 쓰면 안 됨(LINT KSEC)                                                        |
| 6   | (`archive`만) R1 한 줄 판정 + 수치                                                                                                                                                       | 없으면 되돌아감                                                                                                                      |
| 7   | (`archive`만) R2 지표 + 유의성/재현단위 + 표본                                                                                                                                           | 전체 결과표 금지                                                                                                                     |
| 8   | R3 왜 1~2줄                                                                                                                                                                              | "실패했다"로 끝이면 미달                                                                                                             |
| 9   | R4 한계 + "갈리면 원본이 옳다"                                                                                                                                                           | —                                                                                                                                    |
| 10  | R5 코드/설정/운영 변경 여부 단어                                                                                                                                                         | 무변경이면 "무변경"                                                                                                                  |
| 11  | R6 deferral 문장 grep 후 제거                                                                                                                                                            | —                                                                                                                                    |
| 12  | Evidence 는 상대경로 마크다운 링크                                                                                                                                                       | wikilink 로 원본을 걸지 말 것                                                                                                        |
| 13  | Backlinks 대칭                                                                                                                                                                           | —                                                                                                                                    |
| 14  | 폴더 README + LINK-MAP 같은 커밋                                                                                                                                                         | —                                                                                                                                    |
| 15  | staleness: 거짓이 된 기존 노트도 같은 커밋에서 고친다                                                                                                                                    | —                                                                                                                                    |
| 16  | `/wiki-ingest`                                                                                                                                                                           | 에러 0 없이 커밋 금지                                                                                                                |

★4a가 빠지는 게 지금까지 51장이 미분류로 쌓인 원인 중 하나였다(스킬이 kind를 물어본 적이
없었다). `knowledge` 주제(예: "우리 KPI 목표는 산수가 안 맞는다")를 6~9의 조사형 템플릿
그대로 쓰면 판정문이 사실보다 앞에 오는, 사장님이 지적한 형식이 나온다 — 그래서 5에서
종류별로 갈린다.

## 산출

노트 1장 + README + LINK-MAP + (필요 시) 이웃 Backlinks.
