# Marblo v3.0.17 Release Notes

검증 기준: 2026-07-17 `origin/main` 최신 확인 기준으로 #461, #463, #464, #465, #468, #469, #470은 머지 완료. 서버 Firebase Functions 배포 완료분과 3.0.17 클라이언트/Electron 빌드 반영 필요분을 분리해 추적한다.

## 이미 라이브(서버 Firebase Functions 배포됨)

- PR #463: 어드민 `requireAdmin`의 `ADMIN_UID` 누락 케이스를 명확히 실패 처리하고 predeploy 게이트를 추가했다.
  - 릴리스 후 기대효과: 어드민 함수 배포 전 필수 환경변수 누락을 사전에 차단해 운영 중 403/INTERNAL 원인 추적 시간을 줄인다.

- PR #465: 어드민 BigQuery 쿼리의 `completedAt` TIMESTAMP 비교를 수정했다.
  - 릴리스 후 기대효과: Usage/Model 탭의 INTERNAL 오류가 해소되어 어드민 사용량/모델 분석 화면이 정상 조회된다.

- PR #468: 파운더 grant materialization 갭을 선정/가입 양방향 공통 헬퍼와 upsert 트랜잭션으로 근본 수정했다.
  - 운영 결과: 파운더 13명 Pro 백필 실행 완료. 검증값은 `verifiedActiveFounderGrant=13`, `mismatches=0`.
  - 릴리스 후 기대효과: 선정 후 가입, 가입 후 선정 순서 모두에서 Pro grant가 빠지지 않고 일관되게 반영된다.

- PR #469: 어드민 구독지표 그룹(활성/연속구독자, 성장/이탈)을 추가하고 `paidPro` stomp READ 문제를 수정했다.
  - 릴리스 후 기대효과: 활성 구독자, 연속 구독자, 성장/이탈 지표를 어드민에서 직접 확인할 수 있고, paid Pro 상태 조회가 기존 값에 의해 덮이지 않는다.

- PR #470: 텔레메트리 문서의 실제 게이트 동작을 보정하고 서버 `appVersion` 폴백을 `3.0.0`에서 `null`로 수정했다.
  - 현재 상태: PR #470은 `origin/main`에 머지 완료됐고, 서버 Firebase Functions 배포 완료분으로 추적한다.
  - 릴리스 후 기대효과: 구버전/미표기 이벤트가 3.0.0으로 잘못 집계되지 않고 unknown(`null`)으로 남아 릴리스별 분석 왜곡이 줄어든다.

## 릴리스(3.0.17 클라/electron 빌드) 필요

설치앱에는 아직 아래 항목이 미반영되어 있으며, 3.0.17 클라이언트/Electron 빌드로 활성화된다.

- PR #470: 클라이언트 이벤트 payload에 `appVersion`을 추가하고 `__APP_VERSION__`을 flush 경로에서 주입한다.
  - 릴리스 후 기대효과: 실사용자 이벤트에 정확한 앱 버전이 찍혀 DAU, 세션, 리텐션, 기능 사용량을 릴리스별로 분리 분석할 수 있다.

- PR #464: 코덱스 오케스트레이터 resume 재연결에서 모델 인지 resume id를 사용하도록 수정했다.
  - 릴리스 후 기대효과: 코덱스 오케스트레이터 재시작 시 잘못된 세션 식별자로 즉시 종료되는 재연결 실패가 줄어든다.

- PR #461: 텔레그램 폴러의 PTY 전환 구간에서 inbound 메시지가 유실되지 않도록 했다.
  - 릴리스 후 기대효과: PTY handoff 중 들어오는 텔레그램 명령/알림 처리가 끊기지 않아 운영 명령 신뢰도가 올라간다.

- 효과: 이 릴리스가 나가야 실사용자 텔레메트리 게이트(PR #397로 이미 프로덕션 default-ON)가 설치앱에서 실제 유입을 시작한다.
  - 릴리스 후 기대효과: DAU, 세션, 리텐션, 기능 사용량 등 행동지표 축적이 시작되어 베타/프로덕션 운영 판단에 사용할 수 있다.

## 운영 액션

- 파운더 13명 Pro 백필은 비가역 운영 액션으로 완료됐다.
  - 결과: `verifiedActiveFounderGrant=13`, `mismatches=0`.

- 텔레메트리 게이트는 PR #397 기준 프로덕션 default-ON이 이미 적용된 상태다.
  - 비고: PR #470은 문서와 테스트를 이 실제 동작에 맞게 보정하고, `appVersion` 집계 왜곡을 제거한다.

## 릴리스 후 기대효과

- 어드민 Usage/Model 및 구독지표 화면의 운영 가시성이 개선된다.
- 파운더 Pro grant가 선정/가입 순서와 무관하게 안정적으로 materialize된다.
- 3.0.17 설치앱부터 실사용자 텔레메트리 이벤트가 정확한 앱 버전과 함께 축적된다.
- 텔레그램 폴러와 코덱스 오케스트레이터 resume 경로의 운영 안정성이 개선된다.
