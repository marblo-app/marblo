# sync-and-rebuild

`gh pr merge` advances **origin/main** only — the local checkout the running Electron app builds from does not move, so after a merge the app keeps running stale code (one session drifted 21 commits behind, with every merged change silently missing). `v3/scripts/sync-and-rebuild.sh` collapses the catch-up into one command: **pull → (npm ci only if the lockfile moved) → `build:mcp` → renderer**. It is safe by default — on a dirty tree it stops and tells you to handle your local changes yourself (no auto-stash / reset / clean), and it fast-forwards only (no surprise merge commits). Run it as `npm --prefix v3 run sync` (dev mode: the running `npm run dev` Vite server hot-reloads renderer changes) or `bash v3/scripts/sync-and-rebuild.sh --build` for the full production renderer build. It can be invoked from any directory — it targets the v3 build relative to its own path. **Restart the app** afterward for `electron-main` / MCP-server changes, which do not hot-reload, then verify the update landed (file tree reflects new commits, `get_task <agent-id>`, `npm --prefix v3 run worktree:reap`, board TODO→DONE).
