## Why it is listed here

This registry lists individual Korean items; this is the map of the rest of them. It is the discovery layer for a part of the ecosystem that global "awesome" lists do not reach, and it is CC0, so nothing about reusing it is encumbered.

**Measured 2026-07-29:** 28 stars · last upstream push 2026-07-28 · CC0-1.0 · README updated weekly, with a dated "skill of the week" table (most recent entry 2026-07-28 when checked).

## Provenance caveat — read this one

Upstream states plainly at the top of its README that **the repository is operated end-to-end by AI agents**: discovery, categorization, additions, link verification, and the weekly recommendation are all automated, with humans supervising rather than curating.

That is a genuinely interesting artifact and upstream deserves credit for disclosing it, but it changes what the list is evidence of. An entry means an agent found and classified it, not that a person vetted it. Use this as a directory to start from, and apply your own judgment to anything you install from it — the same judgment `community` tier asks of you everywhere else in this registry.
