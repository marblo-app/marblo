## Marblo 3.0.2

안정성·품질 개선 릴리스입니다. (macOS Apple Silicon + Windows)

### 개선

- **텔레그램 채널 안정화** — 에이전트를 여러 개 실행해도 채널이 끊기지 않도록 폴러를 앱 본체로 분리 (409 경합 근본 수정)
- **로그인 초기화 자가복구** — 실행 직후 네트워크 순단으로 인증이 멈추던 문제를 자동 재시도로 해소
- **버그 신고 온보딩** — 새 사용자에게 인앱 버그 신고 안내 팝업 추가
- **모델 배정 정책** — 난도 높은 작업에 최신 상위 모델을 우선 배정
- **파일 트리 루트 인식 개선** — 심링크/하위 폴더 경로에서도 메인 워크트리를 올바르게 인식 (홈 버튼 복구)

### 설치

- **macOS (Apple Silicon)**: `Marblo-3.0.2-arm64.dmg` — 서명·공증 완료
- **Windows**: `Marblo-Setup-3.0.2.exe` — 코드서명 완료

자동 업데이트(electron-updater)로 기존 사용자에게 순차 배포됩니다.
