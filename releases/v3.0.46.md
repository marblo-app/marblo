# v3.0.46 (macOS Apple Silicon · Windows x64) — 고객 리포·회사망·다양한 기기 호환

> Released 2026-10-11 · tag `v3.0.46` · [download](https://github.com/melocream/marblo-releases/releases/tag/v3.0.46)

## Marblo 3.0.46 (macOS Apple Silicon · Windows x64)

우리 맥·마블로 리포가 아닌 **일반 사용자 기기와 고객 리포**에서도 그대로 동작하도록 고친 버전입니다. 3.0.45 의 변경 내용은 그대로 포함됩니다.

### 고객 리포 지원
- GitLab·Bitbucket·사내 git 서버나 원격이 없는 리포에서도 코드 티켓이 PR 게시 단계에서 막히지 않습니다
- GitHub 리포라도 lint/verify 가 아닌 그 리포의 실제 필수 검사(또는 CI 없음)를 기준으로 인수·머지를 판정합니다
- 워커 지시문에서 마블로 리포 전용 규칙(경로·검사 이름)을 빼, 고객 리포에서 엉뚱한 폴더를 고치지 않습니다
- 커밋이 없는 빈 리포는 원인을 알려주고, git 이 아닌 폴더는 공유 폴더에서 실행 중임을 표시합니다
- 한글·일본어·공백 파일명 변경을 '코드 변경'으로 잘못 판정하던 문제를 고쳤습니다

### 회사·다양한 기기 환경
- 회사 프록시 전용망에서 로그인·에이전트·동기화가 프록시를 거쳐 동작합니다
- Full CI 전송이 프록시·사내 DNS·IPv6 전용망에서도 동작합니다(내부망 접근 차단은 그대로)
- Finder·Dock 으로 연 앱에서도 Homebrew 로 설치한 `gh` 를 찾아 PR·머지 상태를 읽습니다
- 팀원(member) 계정 기기에서도 자기 AI 계정으로 에이전트를 배정할 수 있습니다
- 두 기기에서 같은 프로젝트를 운영할 때, 다른 기기의 작업 중인 에이전트를 죽었다고 판정해 작업을 되돌리던 문제를 고쳤습니다
- 다른 기기에서 만든 프로젝트에서도 독립 테스터 인계가 동작합니다
- Windows 에서 에이전트를 끄면 하위 프로세스(node·git·브라우저)까지 함께 종료합니다
- 미션이 gstack 스킬이나 Claude 오케를 전제하지 않습니다 — 스킬이 없으면 바로 알려주고, Codex·Grok 오케에서도 완료를 감지합니다

### 배정·알림
- 워커가 배정 지시를 의심해 거부하고 '진행 중'으로만 남던 문제를 막고, 착수가 확인되지 않으면 알립니다
- AI 계정 문제로 배정이 막히면 조용히 실패하지 않고 알립니다
- 보류한 티켓의 리뷰 알림과 오래된 실패 티켓의 '수정 대상 확인' 알림이 반복되던 문제를 고쳤습니다
- 가이드 탭에 원시 키(`workspace.tab.brain`)가 보이던 문제를 고쳤습니다

### 빌드 품질
- 모든 빌드가 맥↔윈도우 상호호환·디자인·일반 기기 기능 호환을 점검하는 빌드 전 QA 게이트를 통과해야 합니다
