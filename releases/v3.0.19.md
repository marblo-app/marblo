# Marblo v3.0.19

> Released 2026-07-29 · tag `v3.0.19` · [download](https://github.com/melocream/marblo-releases/releases/latest) (macOS Apple Silicon · Windows x64)

This release is mostly about **who does your work** — the orchestrator now spreads tasks across a wider, more diverse set of models instead of leaning on one — plus workspace and terminal fixes that make a running fleet easier to read.

## 🎛️ The orchestrator diversifies models

Before, the orchestrator over-favored a single top model (`claude-opus-5`) for almost everything. It now selects **per task, from evidence**, and deliberately spreads work across the fleet.

- **Evidence-based model selection.** The second selection layer (which concrete model runs a task) is no longer a hardcoded constant — it scores candidates from real signals: task type, cost, and remaining quota. _(#654)_
- **Diversity, three ways.** ε-exploration so it occasionally tries alternatives, tie-band rotation so near-equal candidates take turns, and a UCB1 under-sampled bonus so a model with little data gets a fair shot before being written off. _(#656)_
- **Less single-vendor lock-in on coding.** The generic `coding` tag no longer routes almost everything to one vendor. _(#662)_

Net effect: run a mission and you'll see different tickets land on different models — chosen for fit, not habit.

## 🔀 More models, and bring-your-own

- **Env-swap vendors as first-class workers.** GLM, Kimi, and MiniMax can now be **auto-selected as worker models** — but only when their key is present, so you never accidentally route your first-party credentials to a third-party endpoint. _(#663)_
- **Subscription vs. metered cost, re-modeled.** The router now understands that a coding-subscription model is cheap while quota remains and expensive once it's spent. It prefers your subscription while there's headroom, then overflows to metered vendors — instead of treating every model as a flat price. _(#664)_
- **Grok session resume.** Cleaned-up resume contract so Grok sessions reconnect predictably. _(#657)_

## 🖥️ Workspace & terminal polish

- **Korean / CJK terminal spacing, fixed.** Agent and orchestrator terminals now render Korean without the extra letter-spacing that made scrollback hard to read — a bundled D2Coding font plus a full scrollback reflow after the font loads, so already-printed lines get corrected too. _(#665, #666)_
- Every workspace tab — **Board, Agents, Code, Worktrees, Lanes, Usage, History** — is where you read what the fleet is doing: tickets and their concrete model on the board, a live terminal per agent, per-model cost on Usage, and an append-only ledger on History.

## Install

- **Windows x64**: NSIS installer.
