## Marblo 3.0.44 (macOS Apple Silicon · Windows x64)

3.0.43 을 Windows 에서 실제로 써 보며 나온 문제를 고친 버전입니다. 3.0.43 의 변경 내용은 그대로 포함됩니다.

### 상주 테스터 (Windows)
- PC 이름이 한글 등 영문이 아니면 상주 테스터 풀이 아예 뜨지 않던 문제 수정 — 기기 ID 를 해시 파일명으로 저장(영문 ID 는 기존 파일 그대로 유지)
- 앱을 켤 때 상주 테스터 패널이 '조회 실패'에서 멈추던 문제 수정 — 창의 프로젝트 등록을 잠깐(최대 3초) 기다림
- Windows 에서 테스터 작업공간 준비가 매번 실패하던 문제(디렉터리 fsync EPERM) 수정
- 한 프로젝트의 풀 복원 실패가 다른 프로젝트 풀까지 막지 않도록 분리

### 에이전트 탭·화면
- 에이전트 탭 기본 보기를 모자이크로(작업 중 터미널이 바로 보임)
- 활동 피드를 불러오지 못하면 무한 스피너 대신 안내 문구 표시
- Windows 에서 오케 계정·모델 드롭다운 목록이 흰 바탕에 흰 글씨로 보이던 문제 수정
