## Marblo 3.0.45 (macOS Apple Silicon · Windows x64)

새로 설치한 뒤 바로 쓸 수 있도록 AI 계정 연결을 고친 버전입니다. 3.0.44 의 변경 내용은 그대로 포함됩니다.

### 설치하자마자 바로 연결
- Finder·Dock 으로 연 앱에서도 터미널에서 로그인해 둔 Claude·Codex·Grok CLI 를 찾아, 'Claude 기본 계정 1' 같은 이름의 AI 계정으로 자동 등록합니다 — 연결 버튼을 누르지 않아도 에이전트가 바로 스폰됩니다(3.0.44 새 설치에서 "연결됨인데 스폰 거부" 되던 문제 수정)
- nvm·fnm·asdf 로 설치한 CLI 도 찾습니다
- DeepSeek 등 API 키로 등록한 모델은 계정 없이 바로 스폰됩니다
- 자동 등록이 실패하면 설정 › AI 계정에 원인과 재시도 버튼을 보여 줍니다

### 권한 동의는 처음 한 번
- 첫 실행 창의 한 줄(에이전트가 매번 묻지 않고 작업하도록 허용)로 Claude 권한 수락까지 끝납니다
- 동의가 더 필요하면 화면 앞에 동의 창이 뜨고, '동의하기'를 누르면 Claude 수락 화면이 열린 터미널이 바로 보입니다. 수락하면 막혔던 에이전트가 다시 시작됩니다
- 에이전트 터미널 안에 동의 화면이 뜨면 '동의 대기'로 표시하고 알림을 보냅니다(조용히 멈추지 않음)
- 시작하기 탭의 로그인 단계에서도 남은 동의를 바로 처리할 수 있습니다

### 로그인 버튼
- '현재 CLI 로그인 열기'가 실패하면 이유(명령을 찾지 못함 등)를 화면에 보여 줍니다
- 에이전트 목록의 터미널 행이 실제 상태를 표시합니다

### 가이드
- 가이드 탭: 탭마다 언제 쓰나·사용법·자주 막히는 것, 각 탭의 '?' 버튼으로 바로 이동
- AI 연결 가이드: 처음 설치했을 때·다른 벤더 모델(API 키)·문제 해결
