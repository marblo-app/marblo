# v3.0.42 (macOS Apple Silicon · Windows x64) — 폐루프 수리 3건 + 보드 테스터 칸

> Released 2026-09-30 · tag `v3.0.42` · [download](https://github.com/melocream/marblo-releases/releases/tag/v3.0.42)

## Marblo 3.0.42 (macOS Apple Silicon · Windows x64)

3.0.41 에서 이어지는 **폐루프 자동 검증 수리 3건**입니다. 오늘 이 세 개가 들어가면서 티켓이 제출 → 독립 테스트 → 오케 판정 → 머지까지 실제로 한 바퀴를 돌았습니다.

> 3.0.35 를 쓰고 계신 분들은 이 버전이 다음 공개판입니다. 3.0.36~3.0.41 은 드래프트로만 있었습니다.

### 검증 파이프라인

- **티켓 lease 와 작업공간 lease 를 한 곳에서 파생** (T-2611)
  두 lease 가 각자 만료되면서 일하는 중인 테스터가 잘려나갔습니다. 작업공간 lease 를 티켓 lease 의 정수배로 묶고, 재배정 구멍을 정본 레코드로 닫았습니다.

- **저위험 티켓 소급 면제** (T-2615)
  위험도 기반 테스터 게이트가 소급되지 않아, 이미 머지된 저위험 티켓이 닫히지 않았습니다. 별도 source 값과 5조건 증명으로 해소하되 **고위험 6범주(결제·인증/크레덴셜·마이그레이션/스키마·릴리스/배포·보안게이트/권한·불변원장)는 절대 통과하지 않습니다.**

- **테스터 작업공간 심링크 보존** (T-2599)
  copy 폴백이 심링크를 따라가 격리 판정이 깨졌습니다.

### 보드

- **티켓에 테스터 칸이 담당 칸과 별도로 생겼습니다** (T-2546)
  누가 검사 중인지, 언제 시작했는지, lease 가 얼마 남았는지가 보입니다. 배정 전에는 빈 칸이 아니라 "아직 배정 안 됨" 으로, 만료된 lease 도 화면에 드러납니다. 지금까지는 테스터가 돌고 있어도 화면이 조용해서 멈춘 것으로 읽혔습니다.

### 알려진 잔여 (티켓 등록됨)

- 30분 lease 상한이 여전히 장시간 테스터를 자를 수 있음
- 위험 분류기가 경로 문자열만 보므로 파일명에 의한 오분류가 남아있음 (수리 착수)
- 운영 용량 축 이름 `disk-memory` 가 실제 측정(디스크)과 불일치
