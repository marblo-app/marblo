## Marblo 3.0.20

### 설치 (신규 유저 첫 관문 수리)
- CLI 설치를 공식 네이티브 인스톨러로 전환 — Claude·Codex·Grok·Antigravity = curl(mac/Linux) / irm(Windows), Gemini = npm + 사용자 prefix. npm 전역 권한(EACCES) 문제 근절.

### 팀 협업
- 초대 수락·프레즌스·팀 채팅 미읽음 배지 실동작화
- 코드 머지 = 관리자(owner/admin) 전용 (role-gate)
- 초대 수락 후 프로젝트 저장소 연결 모달 (Clone & 연결 원클릭)

### 스토어
- 공식 항목 권한 배지 정보성 표시 (경고는 미검수 커뮤니티만)
- 항목 docs 링크가 실제 저장소로 · reviewer 에이전트 원클릭 설치

_macOS(arm64) 먼저 게시. Windows 추가 예정._
