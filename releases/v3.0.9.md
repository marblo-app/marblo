## Marblo v3.0.9

### 🔴 P0 버그 수정 — 패키지 앱 marblo MCP 연결 불능 (-32000)
패키지된 Marblo.app/exe에서 에이전트 spawn 시 `marblo` MCP가 `MODULE_NOT_FOUND`로 연결 실패하던 문제를 수정했습니다. `getMCPServerPath()`가 패키지 시 asar 밖 `Resources/dist-mcp`를 올바르게 참조하도록 변경 (#339).

- **영향**: 이 버전부터 패키지 앱에서 에이전트가 marblo MCP에 정상 연결됩니다.
- **검증**: 설치 후 `/mcp`에서 `marblo` connected 확인.
