## Marblo 3.0.43 (macOS Apple Silicon · Windows x64)

3.0.42 이후 열흘치 개선입니다. 폐루프(공급 → 테스터 인계 → 리뷰 재촉) 세 축이 이 빌드에서 실제로 도는 것을 확인했고(공급 24초 · 테스터 착수 51초 · 리뷰 첫 알림 1분), 속도·꺼짐·비용·디스크 문제를 함께 손봤습니다.

### 폐루프·오케스트레이터
- 폐루프 3축 도착 상태를 화면에 표시, 공급을 한 줄 순서표로 정리
- 오케브레인 탭 재구성(요약 패널 + 전체 탭), 미션 통째 삭제
- 앱 재시작 뒤 에이전트 재접속·티켓 계정 연결 복구 강화
- '바쁘게 헛도는' 에이전트를 감지해 멈추고 다음 단계로 다시 이어줌

### 속도·안정성
- 메인 프로세스 정지 계측과 원인 기록, 종료 사유 영속 기록
- 개발 실행 중복 인스턴스 방지, 종료 지연 시 안전 종료
- 끊긴 출력 파이프(EPIPE)로 앱이 꺼지던 문제 수정

### 비용·자원
- Firestore 읽기 계량과 비용 안전망(예산 차단·이상치 알림), 구독 공유로 읽기 감소
- GitHub API 한도 소진 수정 — 미제출 작업 판정이 REST + 캐시로 조회
- 자동 청소: 끝난 워크트리·임시 작업공간·Claude 테스터 임시 파일·유휴 에이전트를 주기적으로 정리(기본 3시간, 유휴 20분), 청소 오류는 단계별로 표시

### 에이전트·모델
- 회사(하네스)·계정을 남은 사용량으로 비교해 고르는 스폰
- GPT-6.1 Sol·Claude Haiku 5.5 등록, Codex 기본 모델 GPT-6.1 Sol
- Codex 도구 인자가 중간에 잘리면 고치지 않고 교체해 잘린 명령이 실행되지 않게 함
- Solar 단계별 재주입, Upstage 실패 응답 트레이스 저장
- 네이티브 CLI 자동 업데이트, 에이전트 헤더에 티켓과 실제 모델 표시

### 웹탭
- 로그인 팝업을 앱 안에서 처리, 에이전트 위임을 출처·기한으로 제한
- 에이전트가 페이지 구조를 읽는 web_tab_describe, 주소창 검색
