# v3.0.22 (macOS Apple Silicon · Windows x64) — 사람+오케 완전체 감사 로그 · Mission Replay P1 · 라우팅 잔여량·다양성

> Released 2026-08-01 · tag `v3.0.22` · [download](https://github.com/melocream/marblo-releases/releases/tag/v3.0.22)

## Marblo v3.0.22

macOS(Apple Silicon) · Windows(x64) 동시 릴리즈.

### 🤝 협업·감사
- **프로젝트 감사 로그에 오케(에이전트) 행위 병합** — 오케가 *어느 사람의 프로젝트에서, 무슨 모델로, 무슨 티켓을* 처리했는지까지 사람 행위와 한 타임라인에. 각 행에 사람/🤖 뱃지. (owner/admin 전용, 구성원별 필터)
- **프로젝트 탭** — 프로젝트 단위 멤버 초대·권한·작업량, 협업 감사 패널
- 멤버 목록 오너 상단 고정 · 멤버 이름 표시 · 채팅 알림 재노출(확인한 메시지) 수정

### 🎬 Mission Replay Phase 1 (비공개 인앱뷰)
- 완료 미션을 타임라인·요약·통계로 조립하는 인앱 뷰. **공유/내보내기 표면 0개**(비공개 우선 — 공개는 Phase 2 편집·마스킹 이후)
- 오케가 라벨링한 ad-hoc 보드 작업도 리플레이로 그룹화

### 🧭 스폰 라우팅
- 잔여 쿼터를 스폰 주요 팩터로 반영 · 모델 다양성 개선(opus5 편중 완화)

### 🐛 도그푸딩 픽스
- 로컬 폴더 열기(숨김파일 토글·붙여넣기·폴더생성) · 파일트리 워크트리 이름 overflow 2층 · 완료이력 기간필터 · Sentry 노이즈 드롭 · 프로젝트 스위처 정리

*(설치 후 재시작하면 새 오케 라우팅·ad-hoc 미션 라벨이 라이브됩니다.)*
