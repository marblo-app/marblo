## 배경

기존 강의(docs/lectures/v3/, 8모듈 ~15.5h)는 "앱으로 SaaS를 처음부터 배포까지" 컨셉이고, 메인 프로젝트 1개(날씨 대시보드)를 v1→v3 비교 위주로 진행한다. **현재 제품의 핵심 사용 경험(보드+레인+오케스트레이터로 Claude Code·Codex 멀티에이전트를 굴려 프로젝트를 개발하는 흐름)이 강의에 제대로 안 담겨 있다.** 이 실제 워크플로우 중심으로 강의를 **다시 찍기 위해 목차/구성/기획을 새로 설계**한다.

## 목표

**"Marblo의 보드·레인·오케스트레이터로 Claude Code + Codex 에이전트 팀을 지휘해, 기초 셋업부터 여러 프로젝트를 실제로 개발해나가는"** 흐름의 새 강의 커리큘럼을 처음부터(목차→레슨 구성→기획) 설계한다.

## 새 강의 컨셉 (반드시 반영)

1. **제품 중심 실사용 흐름** — 슬라이드 설명 최소화, "실제로 마블로를 쓰는 화면"을 따라가는 구성.
2. **기초 온보딩부터**: 최초 **가이드 탭** → **사용/설정·사용량 탭** → **워크트리 체크/연결** → **하네스(Harness) 설치 + CLI 인증** → 첫 프로젝트 준비. (입문자가 따라할 수 있게 0부터)
3. **보드 + 레인 + 오케스트레이터**가 주인공: 자연어로 오케에 요청 → 태스크 분해 → 보드 카드 → 레인에서 에이전트 진행 → 리뷰/머지. 칸반 거버넌스 시연.
4. **멀티에이전트 = Claude Code + Codex** (⚠️ Gemini는 현재 fleet에서 제외됨 — 기존 강의의 "Claude+Gemini+GPT" 표기 갱신. 필요시 Antigravity 언급). 역할 분담(설계/구현/리뷰)을 실제로 보여줌.
5. **프로젝트 여러 개를 점증적으로**: 메인 1개가 아니라, 작은 프로젝트 → 점점 복잡한 프로젝트 몇 개를 해나가며 마블로 기능을 단계적으로 노출(첫 풀사이클 → 멀티에이전트 협업 → 플로우/오케 고급 → 배포).
6. 강의 트랙 포지셔닝·가격은 docs/MVP/V3*커리큘럼.md·v3.1*런칭\_마스터플랜.md(§2.5, §5) 기준 유지.

## 에이전트가 할 일 (산출물)

1. **기존 자료 정독**: docs/lectures/v3/ 전체(1-1~8-4 + 실습*\*.md + HOME.md), docs/MVP/V3*커리큘럼.md, docs/MVP/V3*촬영가이드.md, v3.1*런칭\_마스터플랜.md(강의 관련 절).
2. **현재 제품 기능 확인**: v3 앱의 탭 구조(가이드/보드/에이전트/코드/하네스/사용량/설정 등), 오케스트레이터·레인·워크트리·하네스 설치 흐름을 코드/문서로 파악해 강의에 실제 존재하는 기능만 담기게.
3. **새 커리큘럼 목차 설계** (신규 문서로 작성, 예: docs/MVP/V3\_커리큘럼\_v2.md):
   - 모듈/레슨 구조 (번호·제목·예상 길이)
   - 각 레슨: 학습 목표 / 화면에서 시연할 마블로 기능 / 진행할 프로젝트 단계 / 핵심 메시지
   - 프로젝트 로드맵(어떤 프로젝트를 몇 개, 난이도 점증 순서)
   - 기존 8모듈 대비 변경점 매핑(유지/재구성/폐기/신규) 표
4. 촬영 가이드 갱신 포인트(있으면)도 함께 제안.

## 수용 기준

- 새 커리큘럼 목차 문서가 "가이드탭 온보딩 → 하네스 설치 → 워크트리/연결 → 보드+오케 첫 프로젝트 → 멀티에이전트(Claude+Codex) 프로젝트들 → 배포" 흐름을 명확히 담음.
- 각 레슨에 "어떤 마블로 화면/기능을 시연하는지"가 명시됨(슬라이드 강의 아님).
