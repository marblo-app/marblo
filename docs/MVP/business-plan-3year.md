> **"Cursor는 에이전트 1명. 마블로는 군단."**

- 차별점: 이종 에이전트 동시 오케스트레이션 (경쟁사 없음)

### 인플루언서 & 크리에이터 협업 전략

#### Tier 1: 무료 구독권 시딩 (비용 ₩0, 효과 최대)

| 대상                       | 규모 | 제공         | 기대 효과                        |
| -------------------------- | ---- | ------------ | -------------------------------- |
| AI/개발 유튜버 (5K~50K)    | 20명 | Pro 1년 무료 | 솔직한 사용기 영상 → 유기적 노출 |
| 테크 블로거                | 10명 | Pro 1년 무료 | SEO 백링크 + 리뷰 포스트         |
| X/트위터 개발자 인플루언서 | 15명 | Pro 1년 무료 | 트윗 스레드, 바이럴              |
| 디스코드 커뮤니티 운영자   | 5명  | Pro 1년 무료 | 커뮤니티 내 추천                 |

**접근 방법:**

1. DM으로 개인화된 메시지 (대량 스팸 X)
2. "마블로 앰배서더 프로그램" 이름으로 공식화
3. 사용기 의무 없음 — "써보시고 좋으면 공유해주세요" (강제하면 역효과)
4. 전용 대시보드에서 앰배서더 전환 트래킹

> **비용**: Pro ₩19,000 × 12개월 × 50명 = ₩11.4M (장부상 비용이지만 실제 원가는 거의 0)
> **실제 비용**: 서버 비용만 미미하게 발생, 사실상 무료 마케팅

#### Tier 2: 유료 협찬 리뷰 (월 ₩1~3M)

| 대상                   | 구독자/팔로워         | 비용/건   | 형태                | ROI           |
| ---------------------- | --------------------- | --------- | ------------------- | ------------- |
| 중형 유튜버 (50K~200K) | 개발/AI 채널          | ₩500K~1M  | 10분 사용기 영상    | 높음          |
| 대형 유튜버 (200K+)    | 조코딩, 노마드코더 급 | ₩2~5M     | 전용 리뷰 or 콜라보 | 브랜드 인지도 |
| 팟캐스트               | 개발 관련             | ₩300~500K | 15분 스폰서 멘션    | 중간          |

**비용 vs 무료 구독권 판단 기준:**

- 구독자 5만 미만 → **무료 구독권만** (비용 대비 효과 불확실)
- 구독자 5~20만 → **무료 구독권 + ₩500K~1M 협찬비** (확실한 노출 보장)
- 구독자 20만+ → **₩2~5M 협찬비** (브랜드 인지도 투자)

#### Tier 3: 앰배서더 프로그램 (지속적 파트너십)

| 등급         | 조건                                  | 혜택                                      |

| **체험**     | 앰배서더 신청                         | Pro 6개월 무료 체험 (의무 없음)           |
| **Silver**   | 사용기 영상/블로그 1회 업로드         | Pro 1년 추가 증정 (총 1.5년)              |
| **Gold**     | Silver 달성 시 자동 승급              | 수익 쉐어 10% + 신규 기능 얼리 액세스     |
| **Platinum** | 내부 심사 (지속적 콘텐츠 + 매출 기여) | Pro 평생 무료 + 수익 쉐어 10% + 강의 무료 |

**수익 쉐어 모델** (Platinum):

- 앰배서더 전용 추천 링크 → 추천인의 첫 6개월 구독료 10% 지급
- 예: 앰배서더가 100명 전환 → 100 × ₩19,000 × 6개월 × 10% = ₩1.14M 지급

### 인플루언서 시딩 실행 계획

#### Step 1: 리스트 작성 (런칭 2주 전)

- AI/개발 유튜버 20명 (Claude Code, Cursor 관련 콘텐츠 제작자 우선)

- 디스코드 커뮤니티 운영자 5명

#### Step 2: 개인화 DM 발송 (런칭 1주 전)

```

마블로라는 AI 에이전트 오케스트레이션 도구를 만들고 있는 김동원입니다.

Claude, GPT, Gemini를 하나의 칸반 보드에서 동시에 관리하는 데스크탑 앱인데,

사용기 의무는 전혀 없고, 써보시고 좋으면 자유롭게 공유해주시면 감사하겠습니다.

감사합니다.
김동원 드림
```

## 장기 전략: 도구 → 플랫폼 → 데이터 해자

### 비전 진화

```
Year 1-2: 도구 (에이전트 오케스트레이션 도구)
    ↓ 사용 데이터 축적
Year 2-3: 플랫폼 (AI 팀 매니지먼트 플랫폼)
    ↓ 인사이트 독점
Year 3-5+: 데이터 해자 (모델 성능/비용 벤치마크, 팀 생산성 분석)
```

### 데이터 수집 구현 계획

#### Phase 1 (Year 1): 기본 텔레메트리

- 태스크 생성/완료/실패 이벤트 로깅
- 에이전트별 실행 시간, 토큰 사용량
- 모델별 태스크 유형 매핑
- **구현**: Firestore 이벤트 로그 + Cloud Functions 집계

#### Phase 2 (Year 2): 분석 대시보드

- 사용자별 모델 성능 비교 차트
- 비용 최적화 추천 ("GPT로 바꾸면 월 ₩50K 절약")
- 팀 생산성 트래킹 (Team/Enterprise)
- **구현**: BigQuery 파이프라인 + 앱 내 Analytics 탭

#### Phase 3 (Year 3): AI 기반 인사이트

- 자동 모델 선택 엔진 (데이터 기반)
- 태스크 자동 분해 정확도 95%+
- 산업별/규모별 벤치마크 리포트
- **구현**: 자체 ML 모델 + 익명화 벤치마크 DB
