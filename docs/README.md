# Marblo Docs

Documentation for the Marblo app and its open ecosystem.

- **[Getting Started](getting-started/)** — install Marblo, connect a harness, run your first parallel build.
- **[Concepts](concepts/)** — orchestrator, agents, tickets, worktrees, harnesses, and the Store.
- **[How it works](how-it-works/)** — the mechanism, for developers: two-layer model selection, spawn gates, worktree isolation, safe-merge refusals, closeout, cost attribution, and the audit ledger. Plus **[the hard parts](how-it-works/hard-parts.md)** — which of those are difficult, and which are not.
- **[Harness Store](harness-store/)** — install skills, MCP servers, agents, workflows, and knowledge packs; publish your own.
- **[Orchestration](orchestration/)** — how a goal becomes tickets, model selection, and safe merge.
- **[Recipes & Playbooks](recipes/)** — end-to-end runs: parallel feature builds, large refactors, bug audits, doc harvests, safe merges.
- **[Troubleshooting](troubleshooting/)** — common issues and fixes.
- **[Benchmark](benchmark/)** — how we measure orchestrated work, and our own dogfooding numbers with their sample sizes and gaps stated up front.
- **[Privacy & telemetry](privacy.md)** — exactly what the app sends, what never leaves your machine, how to switch the optional parts off, and how to verify it yourself.
