### P1-1. 빈 조직 화면이 "없습니다" 4연타로 읽힌다

**이번 주 가능: ✅ (카드 1개 추가, 반나절)**

**빈 상태 문구 자체는 합격이다.** 실제 소스 컴포넌트를 렌더해서 확인했다(증거: `A-orghome-empty-1920.png`):

> **조직 전체 사용량 · 아직 집계할 사용량이 없습니다**
> 이 조직에 결합된 프로젝트가 없거나, 조회 기간에 기록된 사용량이 없습니다. **0이 아니라 '기록 없음'입니다.**
> 프로젝트를 결합하고 팀원이 로그인한 앱에서 작업하면 다음 날부터 일별 수치가 쌓입니다.

`usage.empty.why` · `usage.empty.when` 이 화면에서 **실제로 읽힌다.** 문장 하나만 보면 "고장"이 아니라 "아직 안 찼다"로 읽힌다.

**문제는 합쳐졌을 때다.** 결합 프로젝트 0인 조직 홈은 이렇게 쌓인다:

```
아직 집계할 사용량이 없습니다      ← 점선 테두리 카드
아직 집계할 프로젝트가 없습니다    ← 점선 테두리 카드
팀 라벨 — 아직 팀이 없습니다       ← 텍스트
결합된 프로젝트 — 아직 이 조직에 결합된 프로젝트가 없습니다  ← 텍스트
```

같은 톤의 "없습니다"가 4번 연속. 각 문장은 옳은데 **화면 전체는 버려진 페이지로 읽힌다.**
점선 테두리(`border-dashed`)가 두 번 반복되는 것도 "미완성" 신호를 키운다.

어떻게 고치나 — 리디자인 말고 **한 칸 추가**:

- 조직 홈 맨 위에 **"시작하기" 카드 1개**를 둔다. "① 프로젝트를 결합하세요 → ② 팀원이 앱에서 작업하면 → ③ 다음 날부터 여기 채워집니다" 3단계 + `bindForm` CTA 버튼.
- 그 카드가 있으면 아래 4개의 "없습니다"는 **설명**이 되고, 없으면 **증상**이 된다.
- 하위 3개는 접어두거나(`<details>`) 톤을 낮춘다 — 같은 무게로 4번 말할 필요가 없다.

`/org/new` 의 `IntakeLoginRequired` 처럼 **중앙 카드**로 감싸면 된다 — 그 컴포넌트가 이미 잘 만들어져 있으니 패턴만 가져오면 된다.

### P2-3. 로그인 카드가 어디에 로그인하는지 말하지 않는다

**이번 주 가능: ✅ (문구 1줄)**

`/admin` → `/auth/login?redirect=%2Fadmin` 으로 리다이렉트되는데 카드 제목은 그냥 `로그인` 이다.
`redirect` 가 `/admin`·`/org` 일 때 부제 한 줄("관리 콘솔에 로그인합니다") 정도.

## 합격 — 손대지 마라

1. **반응형은 안 깨진다.** 조직 홈을 1920·1366·1280·1024·768·375 여섯 해상도에서 렌더해 `scrollWidth === clientWidth` 확인. **가로 넘침 0.** 표는 `overflow-x-auto` 컨테이너가 32곳.
2. **빈 상태 문구는 화면에서 실제로 읽힌다.** `usage.empty.why`/`when` 이 그대로 나온다. "0이 아니라 '기록 없음'입니다"는 좋은 문장이다.
3. **로딩·에러 상태가 존재한다.** 숫자를 0으로 위조하지 않는다 — `empty`/`notProvisioned`/`disabled`/`restricted`/`unwired` 를 각각 다른 칸으로 그린다. 이건 B2B 로서 제대로 된 설계다.
4. **`/org/new` 는 잘 만들어졌다.** `max-w-md` 중앙 카드, 24px 볼드 제목, `text-zinc-400`(7.76:1) 본문, 풀폭 인디고 CTA.
5. **에러 색은 대비가 충분하다.** `amber-300` 13.8:1.

## 측정 방법 (재현용)

- 라이브: `https://marblo.app` — gstack `/browse` 헤드리스, viewport 1920×1080
- 인증 화면: **못 들어갔다.** Firebase `getAuth()` 기본 퍼시스턴스가 IndexedDB 라 쿠키 임포트로 세션 복원 불가, 자격증명 없음. (오케 판단: 자격증명은 주지 않는다 — 원칙)
- 대신 **실제 소스 컴포넌트를 렌더**했다. 메인 체크아웃의 `node_modules` 를 심볼릭 링크하고 Next dev(`--webpack`; turbopack 은 darwin/arm64 네이티브 바인딩 없어 실패)를 3100 에 띄운 뒤, `src/app/[locale]/zzlookfeel/` 임시 라우트에서 `OrgHomeView`·`OrgUsageSection`·`OrgOutcomesSection` 을 `empty`/`loading`/`error` 봉투로 렌더.
  **가짜 사업 데이터는 넣지 않았다** — 빈 상태 자체가 판정 대상이다.
  ★임시 라우트·더미 `.env.local`·`node_modules` 심볼릭 링크·`.next` 는 감사 종료 시 **전부 삭제**했다(`git status` 클린).
- `/admin` 사업 분석 탭의 데이터가 찬 상태는 콜러블이 필요해 **직접 못 봤다.** 밀도·위계 판정(P1-3)은 소스 정적 측정이다.
