### 강의용을 왜 못 만들었나 (게으름이 아니라 차단 상태)

두 가지가 겹칩니다. ① 사장님이 이번 심사를 구독 단독으로 접수하기로 결정했고,
② 설령 넣고 싶어도 아래 가드 때문에 캡처할 화면이 존재하지 않습니다.

`marblo-web/src/app/[locale]/checkout/page.tsx` 에 의도적 가드가 있습니다.

```
// 강의 실결제 차단(A안): 강의 콘텐츠 미준비 상태이므로 강의 체크아웃 진입
// 자체를 막고 강의 상세("출시 알림 받기")로 돌려보낸다. 직접 URL 진입도 차단.
useEffect(() => {
  if (type === "lecture") { router.replace(.../lectures/${lectureSlug}) }
}, [...]);
```

- 이 리다이렉트는 `type === "lecture"` 이면 **무조건** 실행됩니다.
- 바로 아래 auth 가드에 `if (type === "lecture") return;` 이 있어, **로그인 여부보다 먼저** 동작합니다.
- 따라서 강의는 '메인 → 상품 선택 → **결제 → 결제창**' 중 뒤 두 단계가 도달 불가입니다.
- 없는 화면을 모크업으로 지어내면 심사 서류 위조가 되므로 만들지 않았습니다.

**재개 조건:** 사장님이 강의 판매 가능 여부를 결정하고 위 `useEffect` 를 제거하면,
뼈대 그대로 캡처만 채워 완성됩니다. 그때까지 카드사 심사에는 **정기결제본만** 제출하십시오.

  (정기결제본보다 항목이 많음). 현재 푸터 캡처에 둘 다 포함되어 있어 문제없습니다
