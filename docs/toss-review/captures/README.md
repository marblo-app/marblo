## 규칙

- ★임의 이미지·모크업·합성 금지. 심사 제출 서류입니다.
- ★실결제 승인까지 진행하지 마십시오. 결제창 표시까지만 캡처합니다.
  (현 `06_1` 은 카드번호 미입력 상태로 촬영했습니다.)
- ✅ `test_ck_` 테스트 모드 결제창을 그대로 씁니다. 라이브 키는 심사를 통과해야
  발급되므로 테스트 키 상태로 심사받는 것이 정상 절차입니다.
- ★재촬영 시에는 브라우저를 새로 띄워(캐시 배제) 화면이 최신인지 확인한 뒤 찍으십시오.
  실제로 이 확인에서 `/pricing` 연간 제공기간 누락(PR#536 로 수정)을 잡았습니다.
