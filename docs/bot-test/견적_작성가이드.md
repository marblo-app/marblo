# 스티커 제조 견적 작성 가이드

> **가공 샘플 자료입니다.** 아래 수치와 규칙은 테스트 전용이며 실제 거래처·실거래 단가·연락처·개인정보가 아닙니다.

## 1. 견적서 필수 항목

- 견적일, 견적번호, 고객명(신규 클라이언트 등 일반명 가능)
- 제품명, 재질/표면, 인쇄 방식·색상, 크기, 수량
- 재료비, 인쇄비, 재단비, 수량할인, 판비·세팅비, 마진, 공급가, VAT, 총 견적가
- 납기, 견적 유효기간, 결제·배송 조건, 유의사항

## 2. 엑셀에서 숫자 찾기

모든 숫자는 같은 이름의 시트와 컬럼에서 찾는다.

- 재료: **재질단가** 시트의 `재질명`, `표면/색상`, `규격 기준`, `단가(원/장)`
- 인쇄: **인쇄비** 시트의 `인쇄방식`, `색상`, `규격 기준`, `단가(원/장)`
- 가공: **재단·통재비** 시트의 `가공명`, `규격 기준`, `단가(원/장)`
- 수량할인: **수량구간별 단가** 시트의 `최소수량(장)`, `최대수량(장)`, `할인율`, `계산 적용`
- 고정비: **고정비(판비·세팅)** 시트의 `항목`, `적용조건`, `금액(원)`
- 마진: **마진율 가이드** 시트의 `구분`, `권장마진율`, `적용 기준`

## 3. 계산 순서

1. **재료**: `재질단가`.`단가(원/장)` × 수량.
2. **인쇄**: `인쇄비`.`단가(원/장)` × 수량.
3. **가공**: `재단·통재비`.`단가(원/장)` × 수량.
4. **수량 할인**: 수량이 들어가는 구간을 `수량구간별 단가`에서 찾아 변동비 합계에 `1-할인율`을 곱한다. 할인은 재료비·인쇄비·가공비에만 적용하고 고정비에는 적용하지 않는다.
5. **고정비**: `고정비(판비·세팅)`의 해당 `금액(원)`을 주문 1건 기준으로 더한다.
6. **마진**: `마진율 가이드`.`권장마진율`을 원가(할인 후 변동비 + 고정비)에 곱해 더한다. 일반 스티커는 권장 20%를 사용한다.
7. **VAT**: 공급가의 10%를 부가하고, 최종 견적가는 공급가 + VAT로 계산한다. 원 단위에서 반올림한다.

## 4. 수량 할인·조건 문구

수량 구간은 경계값을 포함한다. 예를 들어 5,000장은 `5,000~9,999장` 구간이다. 여러 규격·재질을 한 주문에 섞을 경우 수량을 합산하지 말고 품목별로 구간을 적용한다.

견적 유효기간은 발행일로부터 **14일**이며, 원자재·운송 조건이 바뀌면 재산정한다. 표준 납기는 교정 승인 후 **영업일 7일**로 기재한다. 도무송 칼형·추가 후가공·배송비는 별도 협의 항목으로 표시한다.

## 5. 끝까지 계산한 예시

조건: **5,000장 / 유광 코팅 / 50×50mm / 4도 컬러 / 도무송 재단**

1. `재질단가`에서 합성지·유광 코팅·50×50mm를 찾아 `단가(원/장)` **0.18원** → 재료비 `0.18 × 5,000 = 900원`.
2. `인쇄비`에서 디지털 인쇄·4도 컬러·50×50mm를 찾아 `단가(원/장)` **0.12원** → 인쇄비 `0.12 × 5,000 = 600원`.
3. `재단·통재비`에서 도무송 재단·50×50mm를 찾아 `단가(원/장)` **0.05원** → 재단비 `0.05 × 5,000 = 250원`.
4. 변동비 합계는 `900 + 600 + 250 = 1,750원`. `수량구간별 단가`의 5,000~9,999장 `할인율` **5%**를 적용 → `1,750 × (1 - 0.05) = 1,662.50원`.
5. `고정비(판비·세팅)`에서 판비 **3,000원** + 세팅비 **1,200원** → 고정비 **4,200원**.
6. 할인 후 원가는 `1,662.50 + 4,200 = 5,862.50원`. `마진율 가이드`의 일반 스티커 `권장마진율` **20%** → 마진 `5,862.50 × 0.20 = 1,172.50원`.
7. 공급가 `5,862.50 + 1,172.50 = 7,035원`. VAT 10%는 **703.50원**.
8. 최종 견적가 `7,035 + 703.50 = 7,738.50원` → 원 단위 반올림 **7,739원 (VAT 포함)**.

따라서 이 예시의 견적서에는 공급가 **7,035원**, VAT **704원(반올림 표시)**, 최종 견적가 **7,739원**을 기재한다.
