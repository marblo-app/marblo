# 마블로봇 견적봇 테스트 자료

이 폴더는 마블로봇 **견적봇**이 원가 자료를 참고해 스티커 제조 견적을 작성하는 테스트용 기반 자료입니다.

## 봇 설정

Knowledge의 `root_path`를 이 폴더로 설정하세요.

> 모든 수치와 규칙은 가공 샘플이며, 실제 거래처·실거래 단가·연락처·개인정보가 아닙니다.

`견적_작성가이드.md`가 `스티커_제조원가.xlsx`의 실제 시트명과 컬럼명을 가리키므로, 가이드를 먼저 읽고 엑셀에서 해당 숫자를 찾아 계산할 수 있습니다.

자료 구성:

- `스티커_제조원가.xlsx`: 재질·인쇄·재단·수량할인·고정비·마진율 샘플
- `견적_작성가이드.md`: 견적 필수 항목, 계산 순서, 조건 문구, 종단 계산 예시
