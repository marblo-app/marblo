## 플랜별 타겟

### Free — 체험/학습용

- 개인 개발자가 Marblo를 처음 체험
- 프로젝트 1개, 에이전트 2개로 기본 워크플로 경험
- 칸반 보드 + MCP 연동 + 터미널

### Pro ($15/mo, ₩19,000/월) — 개인 개발자/프리랜서

- 개인 무제한 (프로젝트·에이전트 모두 무제한)
- Flow 에디터로 에이전트 워크플로 설계
- 오케스트레이터로 자연어 태스크 분해
- **핵심 가치**: 혼자서도 팀처럼 일하기 (vs Cursor $20 = -25%)

### Team ($25/seat/mo, ₩29,000/seat/월) — 팀/소규모 회사

- 팀원과 프로젝트 공유 및 실시간 협업
- per-seat 과금 (5인 팀 = ₩145K/월, vs Cursor Team $40 × 5 = ₩280K → -48%)
- **핵심 가치**: 팀 전체의 AI 에이전트 오케스트레이션

### Team Plus ($49/seat/mo, ₩59,000/seat/월) — B2B 도입

- Team 기능 + SSO (Auth0/Clerk) + 감사 로그 노출 + 우선 지원 (Slack)
- B2B 영업 진입 SKU. 보안 심사 통과형
- **핵심 가치**: 엔터프라이즈 도입 직전 단계 검증용

### Enterprise (Contact Sales) — 기업/기관

**타겟**: AX 강의 → 시연 → 리드 유치 → 기업 도입

**대기업/공기업이 셀프서브 SaaS를 못 쓰는 이유**:

- 개인 카드결제 불가 (구매팀 통한 PO 필요)
- 보안 심사 필수 (데이터 저장 위치, 접근 제어)
- 인원수 x 월요금 방식은 예산 잡기 어려움
- 세금계산서 + 연간 계약 필수
- 너무 저가면 신뢰 문제 (공기업 특성)

### 영업 플로우

1. **리드 생성**: AX 강의/세미나에서 Marblo 시연
2. **Contact Sales**: 미팅 → 요구사항 파악 → 견적서 발송
3. **PoC**: 2~4주 무료 트라이얼 (E1 규모, 최대 10인)
4. **보안 심사**: 데이터 처리 방침, 접근 제어, 암호화 등 대응
5. **계약 체결**: 연간 계약 + 세금계산서 발행
6. **온보딩**: 초기 세팅 지원 + 사용자 교육 (1~2회)

## 결제 시스템

### 해외 결제: Paddle

- 글로벌 결제 (신용카드, PayPal 등)
- 세금 자동 처리 (VAT, Sales Tax)
- Paddle Price ID로 플랜 관리
- 환경변수: `VITE_PADDLE_CLIENT_TOKEN`, `VITE_PADDLE_PRO_PRICE_ID`, `VITE_PADDLE_TEAM_PRICE_ID`

### 국내 결제: TossPayments

- 한국 결제 (카드, 계좌이체, 간편결제)
- KRW 원화 결제
- 빌링키 기반 정기결제
