# Getting Started

1. **Install Marblo** — [marblo.app/download](https://marblo.app/download) (macOS · Windows).
2. **Connect a harness** — sign in to a CLI (Claude Code, Codex, …) or bring a vendor key (BYOM).
3. **Open a project** — pick a folder; Marblo registers it and starts the orchestrator.
4. **Run your first parallel build** — describe a goal, or fire Quick Lanes to run several agents at once.

Full walkthrough: [marblo.app/en/guide](https://marblo.app/en/guide).
