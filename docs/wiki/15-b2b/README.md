# 15-b2b

> **한 줄 판정**: B2B는 `10-offerings`의 현재 제공물이 아니라, 고객 인스턴스가 아직 없는 조직 기능의 확정 설계·도입 경로다. 독립 도메인으로 보관한다.

`10-offerings`는 이미 운영·제공되는 실물을 담는다. 이 묶음은 Phase 0만 배포됐고 조직 컬렉션 인스턴스는 모두 0건이므로, 제공물로 가장하면 상태를 숨긴다. 다만 네 판정이 쌓였으므로 새 폴더의 최소 기준(3노트)을 넘긴다.
