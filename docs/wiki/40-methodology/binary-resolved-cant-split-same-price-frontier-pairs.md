# 이분법 완주율은 동일가 프런티어 모델을 갈라내지 못한다

> **한 줄 판정**: ★채택 — 단가가 같은 두 프런티어 모델(예: $10/$50 로 동일)을 이분법 완주율(`resolved` 0/1)로 가르려면, 실측 불일치율(ψ=0.159) 기준 McNemar 검정력 계산상 진짜 격차 **5%p** 에도 **497문제**(회차 $1,240~2,330)가 필요하다. 실제로 돌린 12문제 라운드에서도 관측 격차(1문제, 8.3pt)가 95%CI(±21.1pt) 안에 통째로 들어가 **통계적으로 구분 불가**였다.

## 무엇을 물었나

같은 단가의 두 프런티어 모델을 자체 SWE-bench 하네스로 비교할 때, "완주(F2P 전부 ∧ P2P 전부) 개수가 더 많다"는 관측만으로 우열을 말해도 되는가. 안 된다면 몇 문제를 돌려야 그 관측이 신뢰할 수 있는가.

## 무엇을 했나

자체 하네스의 실측 짝지은 불일치율(ψ, 프런티어 쌍이 같은 문제에서 서로 다른 결과를 낼 확률)을 구하고, McNemar 검정(α=.05 양측, 검정력 80%)으로 진짜 격차별 필요 표본 수를 계산했다. 같은 데이터로 연속 축(비용·토큰·소요시간, 짝지은 t검정)의 필요 표본 수도 계산해 대조했다. 이후 실제로 12문제×3모델 라운드를 돌려 계산과 관측을 대조했다.

## 결과 (수치)

| 진짜 격차 | 이분법(McNemar)에 필요한 문제 수 | 연속 축(짝지은 t검정, 효과크기 d)에 필요한 문제 수 |
| --------: | -------------------------------: | -------------------------------------------------: |
|      15%p |                           **54** |                                     d=0.8 → **15** |
|      10%p |                          **123** |                                     d=0.5 → **34** |
|   **5%p** |                          **497** |                                        d=0.35 → 67 |
|       3%p |                        **1,385** |                                                  — |

- ψ=0.159 는 프런티어 쌍별 실측 일치도 84.1%(불일치 15.9%)에서 나온 값 — 표본 12문제, 프런티어 모델 10~11종 조합.
- **천장에 가까울수록 악화**: 다른 실측 조건에서 ψ=0.05 로 떨어지면 5%p 격차는 **어떤 표본크기로도 검출 불가**(진짜 차이가 불일치율을 못 넘음).
- 실측 검증(3모델 라운드, n=12): `claude-fable-5-1` 11/12(91.7%) vs `gpt-6-astra` 10/12(83.3%) — 관측 격차 **1문제(8.3pt)**, 95%CI 반폭 **±21.1pt**. 격차가 CI 안에 통째로 들어가 셋은 완주율에서 **구분 불가**.
- 같은 라운드의 **연속 축(비용)** 은 반대로 깨끗이 갈렸다 — 해결 1건당 정가환산 비용이 두 프런티어 사이에서 **2.6배** 차이(완주율 격차는 노이즈 폭 안).

## 왜

이분법은 문제당 정보량이 **1비트**뿐이라, 짝지은 불일치율(ψ)이 필요 표본의 상한을 정한다. 프런티어 모델일수록 같은 문제를 같이 맞히거나 같이 틀리는 비율이 높아(천장 효과) ψ 가 낮아지고, 그러면 필요 표본이 기하급수적으로 커진다. 연속 축(비용·토큰·시간)은 문제당 정보량이 실수값이라 같은 효과크기를 훨씬 적은 표본으로 검출한다 — 두 축의 표본 요구량이 겹치지 않는 이유가 여기 있다.

## 한계 / 정직성

- ψ=0.159 는 **특정 문제셋**(django, 12문제)의 실측치다. 문제셋이 바뀌면(예: TypeScript 문제 확대) ψ 도 다시 재야 하고, 이 문서의 문제 수 표는 그 문제셋에서만 유효하다.
- 라운드 실측(n=12)은 **사후 검정**이지 사전 시뮬레이션이 아니다 — 검정력 계산이 맞다는 것을 확인했을 뿐, 새 조건에서의 예측치는 아니다.
- 반복 런이 0회다(같은 문제·같은 모델을 두 번 돌린 적이 없다) — 재실행 분산은 이 계산에 안 들어갔다.
- **수치가 갈리면 원본이 옳다.**

## 실제 영향

코드 무변경. 처방(채택): 완주율 하나로 프런티어 모델 우열을 결론 내지 않는다. 완주율과 함께 **연속 축(비용·시간)을 1급 지표로 병기**하고, 완주율 격차가 **그 표본 수에서 검정력이 확보되는 최소 격차 미만**이면 "구분되지 않았다"고 쓴다 — 더 작은 격차를 "근소 우위"로 읽지 않는다.
