# 마블로봇 메시징 단일 소스

판정: 첫 캠페인은 "새 AI 구독을 팔지 않고, 개발자가 이미 쓰는 CLI 에이전트 구독을 마블로 안에서 더 넓게 쓰게 한다"를 중심에 두는 편이 가장 방어 가능하다.

이 노트는 문구 확정본이 아니다. 사장님이 유튜브·랜딩·README 문구를 결정할 수 있도록 후보와 근거, 리스크를 한곳에 둔다. 실제 랜딩·README 파일은 이 티켓에서 고치지 않는다.

## 지금 되는 것 / 곧 되는 것 / 아직 없는 것

| 구분 | 사실 | 홍보 문구 기준 |
| --- | --- | --- |

## 그록봇 대조표

| 축 | 그록봇으로 보이는 주장 | 마블로봇/마블로의 확인된 사실 | 근거와 한계 |
| --- | --- | --- | --- |
| 실행 위치 | 확인 필요. 이름상 Grok 계열 봇/서비스일 가능성이 있으나, 이 저장소 안에는 사장님 아티팩트 외 독립 사양 근거가 없다. | Electron 데스크톱 앱에서 사용자의 로컬 프로젝트·워크트리·CLI 하네스를 실행한다. | 랜딩 FAQ는 "모든 실행이 로컬 머신"이라고 말한다. 코드에는 Grok CLI 하네스와 모델 레지스트리가 있다. 그록봇 외부 사양은 이 노트에서 단정하지 않는다. |
| 조율 | 확인 필요. 단일 봇 대화형 경험인지, 여러 CLI 에이전트를 보드 티켓으로 조율하는지는 현재 근거가 없다. | 오케스트레이터가 보드 티켓, 역할, dispatch_task, 진행 activity, review 상태를 묶는다. 마블로봇 갤러리는 별도 spawn 경로가 아니라 기존 오케스트레이터 dispatch 지시를 사용한다. | `buildBotDispatchInstruction()`은 "Create a board ticket first, then dispatch"를 요구한다. |
| 모델 선택 | 새 구독 또는 특정 Grok 계정 중심일 가능성이 캠페인상 비교 포인트지만, 외부 사실은 확인 필요. | 봇 정의 model 축은 `claude`, `codex`, `grok`, `deepseek`, `solar`, `local` 중 선택한다. 마블로 자체 요금은 조율 비용이고 AI 사용료는 사용자 기존 계정 부담이다. | `BOT_MODELS`와 랜딩 FAQ. 단 각 모델별 사용 가능 여부는 사용자의 CLI 로그인/키 상태에 좌우된다. |
| 인터페이스 | 확인 필요. 챗봇형 인터페이스인지, CLI/웹/앱 중 어디인지 이 저장소 근거만으로 단정하지 않는다. | 마블로는 데스크톱 앱 안의 보드·터미널·워크트리·갤러리·오케스트레이터 흐름이다. | 홈 카피와 코드 구조. 모바일 앱은 없다. |

대조표의 톤: "그록봇은 못 한다"가 아니라 "마블로가 확실히 말할 수 있는 차이는 실행 위치·조율·모델 선택·인터페이스의 조합"이다.

## 대상 분리

개발자 캠페인은 "CLI 에이전트를 이미 쓰는 사람"을 부른다. 이 사람에게는 추가 AI 구독보다 기존 Claude Code·Codex·Grok 사용량을 더 잘 쓰게 하는 말이 먹힌다. 설치 장벽도 낮다. 이미 터미널, Git, PR, 워크트리, README를 안다.

비개발자 캠페인은 "AI 비서가 업무를 대신해 주길 바라는 사람"을 부른다. 이 사람에게 CLI 설치, Git 레포, 워크트리, MCP 설정은 첫 장벽이다. 같은 영상에서 "CLI 에이전트"와 "비서"를 섞으면 개발자는 제품이 장난감처럼 보이고, 비개발자는 설치 전에 이탈한다.

따라서 첫 캠페인은 개발자에게 좁혀야 한다. 비개발자 캠페인은 트리거 UI, 비개발 artifact contract, 사용법 한 장, 모바일/채널 표면 중 적어도 하나가 갖춰진 뒤 별도로 연다.

## 무료 문구 기준

무료는 할인으로 말하지 않는다. 할인은 가격 비교 게임을 만들고, 그록이 무료를 따라오면 무력해진다. 무료는 참여 대가로 말한다.

좋은 형태:

- "베타 기간에는 무료로 열고, 실제 사용 피드백을 제품에 반영합니다."
- "성실 피드백을 주신 분께 Pro 기간을 드립니다."
- "지금은 외부 실매출이 사실상 0원인 단계라, 가격보다 사용 사례와 피드백이 더 중요합니다."
- "AI 사용료는 포함되지 않습니다. 각 에이전트는 사용자의 기존 CLI/API 계정으로 실행됩니다."

피할 형태:

- "그록봇도 무료니까 마블로봇도 무료"
- "무료니까 써보세요"
- "비서가 다 해줍니다"
- "추가 비용 0원"만 단독으로 쓰기. 이 문장은 AI 사용료를 마블로가 부담한다는 오해를 낳을 수 있으므로 "이미 내고 있는 CLI 구독을 더 활용"과 붙여야 한다.
