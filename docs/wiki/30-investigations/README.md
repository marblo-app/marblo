# 30-investigations

판정이 남는 시도. 하위폴더는 **무엇을 건드렸나** 축이고, 한 묶음에 노트 3건이 모이면 판다. 시간·담당자·판정값 폴더는 금지.

1판은 평평한 인덱스만. 첫 값은 탐구 더미가 아니라 방법론 허브([[empty-query-first]])와 기각 원장([[do-not-retry]])이다.
