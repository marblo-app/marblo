# 조직·분석 화면 시연 런북

발표일: **[발표 날짜를 여기에 적어주세요]**

이 문서는 발표 단상에서 그대로 따라가시는 클릭 순서입니다. 화면 이름과 버튼 이름은 전부 지금 배포된 화면의 실제 문구입니다.

## 0. 제일 먼저 아셔야 할 것 — 시각 축

**오늘 만들어도 "숫자"는 오늘 안 뜹니다.** 화면 자체(빈 상태 문구·조직 홈·초대 화면)는 지금 당장 다 보여드릴 수 있지만, 대시보드에 실제 비용·성공률 숫자가 채워지는 것은 **결합한 다음 날부터**입니다 — 이건 버그가 아니라 이 화면이 태생적으로 그렇게 설계돼 있습니다(화면 문구 그대로: "프로젝트를 결합하고 팀원이 로그인한 앱에서 작업하면 다음 날부터 일별 수치가 쌓입니다").

지금 확인된 그 "다음 날"의 기준일은 **2026-09-07**입니다. 즉:

| 언제                                         | 무엇을 보여줄 수 있나                                                                                                                                                                                |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **2026-09-06(오늘)**                         | 조직 생성 · 프로젝트 결합 · 멤버 초대 **화면 전부** 실제로 보여드릴 수 있습니다. 다만 대시보드 숫자 칸은 "아직 집계할 사용량이 없습니다"(빈 상태)로 뜹니다 — 결합을 안 해서가 아니라 날짜 때문입니다 |
| **2026-09-07 이후, 팀원이 실제로 작업한 뒤** | 그날부터의 활동이 숫자로 뜨기 시작합니다. 그 이전 활동은 이 화면에 영영 안 잡힙니다                                                                                                                  |

★**발표가 09-06 당일이면**: "조직 만들고 초대하는 흐름"까지는 라이브로 보여드리고, 숫자 화면은 "내일부터 이렇게 채워집니다" 화법으로 넘기시는 것을 권합니다. 억지로 숫자를 보여주려 하면 빈 화면만 나옵니다.
★**발표가 09-07 이후면**: 아래 "발표 D-1에 해두실 일"을 하루 전에 마치면 당일 진짜 숫자를 보여드릴 수 있습니다.

## 1. 발표 D-1에 해두실 일 (당일 숫자를 보여주시려면)

1. 아래 "2. 조직 만들기" ~ "5. 팀원 초대하기"까지 **하루 전에 미리 끝내두세요.**
2. 초대받은 두 분(예: datagadapida, melocream)이 링크를 열어 **수락까지 완료**하도록 해주세요.
3. 두 분이 그 프로젝트에서 **실제로 앱을 로그인해 에이전트를 한 번 이상 돌려주세요.** 로그인만 하고 아무 작업도 안 하면 사람별 칸이 계속 비어 있습니다.
4. 당일 아침, 아래 "6. 대시보드 보기"로 미리 한 번 열어보고 숫자가 채워졌는지 확인하세요.

당일 아침에 처음부터 시작하시면 시간이 부족합니다 — 이 4단계는 **반드시 전날** 끝내주세요.

---

## 2. 조직 만들기

1. 브라우저에서 **`marblo.app/org/new`** 로 직접 이동합니다.
   - ★**함정 1**: 화면 위쪽 메뉴(헤더)에 조직 페이지로 가는 링크가 아직 없습니다. 주소창에 직접 입력해야 합니다.
   - 로그인이 안 돼 있으면 "로그인이 필요합니다" 화면이 뜹니다 → **로그인** 버튼으로 평소 쓰시는 계정으로 로그인하시면 됩니다.
2. **"조직 이름을 정해주세요"** 화면이 뜹니다. 입력칸(조직 이름)에 조직 이름을 입력합니다(예: "하이프마크").
3. **조직 만들기** 버튼을 누릅니다.
4. **"{조직 이름} 이(가) 준비됐습니다"** 화면이 뜹니다. **조직 홈으로** 버튼을 누릅니다.

---

## 3. 조직 홈 화면 첫인상

조직 홈(`marblo.app/org/<조직id>`)에 들어오면 위에서 아래로 이렇게 보입니다:

1. **"조직 전체 사용량"** — 지금은 "아직 집계할 사용량이 없습니다" (정상, §0 참고)
2. **"작업 성공·실패"** — 지금은 "아직 집계할 프로젝트가 없습니다"
3. **"팀 라벨"** — "아직 팀이 없습니다"
4. **"결합된 프로젝트"** — "아직 이 조직에 결합된 프로젝트가 없습니다"

이 아래로 화면을 **스크롤**하면 실제로 누르는 버튼 두 개가 나옵니다: **프로젝트 결합하기**, **멤버 초대하기**.

---

## 4. 프로젝트 결합하기

1. **프로젝트 결합하기** 버튼을 누릅니다 → "프로젝트를 이 조직에 결합" 폼이 펼쳐집니다.
2. **프로젝트** 드롭다운에서 결합할 기존 프로젝트를 고릅니다.
3. **팀** 항목에서 셋 중 하나를 고릅니다: 기존 팀 / **＋ 새 팀 만들기**(누르면 팀 이름 입력칸이 나옵니다, 예: "데이터팀") / "팀 없음 — 소규모 조직이면 이대로 두세요".
4. **결합** 버튼을 누릅니다 → "프로젝트가 결합되었습니다." 메시지가 뜨고, 위쪽 "결합된 프로젝트" 목록에 방금 결합한 프로젝트가 나타납니다.

---

## 5. 팀원 초대하기

1. **멤버 초대하기** 버튼을 누릅니다 → "멤버 초대" 폼이 펼쳐집니다.
2. **초대할 사람의 이메일**에 상대 이메일을 입력합니다(예: datagadapida의 이메일).
3. **조직 역할**을 고릅니다 — "관리자" 또는 "멤버" 중 하나(소유자 역할은 초대로 줄 수 없습니다).
4. **"프로젝트에도 함께 초대 (선택)"** 아래에 방금 결합한 프로젝트가 체크박스로 보입니다.
   - ★**함정 2 — 제일 중요합니다**: 이 체크박스를 **반드시 체크**하세요. 체크하지 않으면 그 사람은 조직에만 들어오고 **그 프로젝트의 멤버가 되지 않아, 나중에 "사람별" 화면에 이름이 뜨지 않습니다.**
5. **초대 링크 만들기** 버튼을 누릅니다 → "초대 링크가 준비되었습니다" 화면이 뜨고 링크가 표시됩니다.
   - 안내 문구: "이 링크를 복사해 초대할 사람에게 직접 전해 주세요 — 자동으로 발송되지 않습니다." 즉 **메일이 자동으로 가지 않습니다.**
6. **링크 복사** 버튼을 눌러 링크를 복사하고, 슬랙·문자 등으로 직접 전달합니다.
7. **다른 멤버 초대하기** 버튼으로 같은 과정을 melocream에게도 반복합니다.
8. (선택) 폼을 닫으면 그 아래에 **"대기 중인 초대"** 목록이 보입니다 — 아직 수락 안 한 초대가 여기 뜨고, 잘못 보낸 링크는 여기 **취소** 버튼으로 무효화할 수 있습니다.

**받는 사람 쪽:** 전달받은 링크를 열면 "{조직 이름} 팀 초대" 화면이 뜹니다. 로그인/가입 후 **"소속을 확인해 주세요"** 화면에서 **수락하고 참여** 버튼을 누르면 즉시 조직·프로젝트 멤버가 됩니다.

## 6. 대시보드 보기

조직 홈으로 돌아오면(또는 새로고침):

- **"조직 전체 사용량"**: 09-07 이후 실제 활동이 있으면 팀·프로젝트별 비용·토큰이 표로 뜹니다. 아직이면 여전히 빈 상태 문구가 뜹니다(§0).
- **"작업 성공·실패"**: 그 프로젝트 티켓의 완료/실패/진행 중 건수와 성공률.
- **"사람 · 에이전트와 모델"**: 프로젝트 행을 **펼치기** 버튼으로 열면 그 프로젝트에서 일한 사람별 행이 나오고(예: datagadapida, melocream 각자 한 줄), 각 사람 아래에 비용·모델별·에이전트종류별 분해가 보입니다. 다시 **접기**로 닫을 수 있습니다.
  - 화면 맨 아래에 안내 문구가 있습니다: "이 화면은 에이전트에게 무엇을 시켰는지, 무엇이라 답했는지, 어떤 명령을 돌렸는지, 어떤 파일을 열었는지를 절대 보여주지 않습니다. 티켓과 병합, 모델과 금액만 담습니다." — **발표 중 이 문장을 그대로 인용하시면 "How는 감춘다"는 방침을 화면이 스스로 증명합니다.**
  - ★사람별 "성공률" 칸은 이번엔 아직 안 뜹니다 — 화면 문구: "아직 재지 않습니다. 작업 결과는 사람 표시 없이 쌓이고, 그것을 사람과 잇는 부분이 아직 열리지 않았습니다." 계정 축(티켓 완료/실패 건수)은 위 "작업 성공·실패"에서 이미 보여드렸으니, 이 칸이 비어 있어도 발표 흐름엔 지장 없습니다.

## 7. 실패 상황 — 단상에서 이럴 수 있습니다

**비밀번호를 잘못 입력했을 때**
지금은 "이메일 또는 비밀번호가 올바르지 않습니다."라는 문장이 뜹니다(이전엔 알아보기 어려운 오류 코드가 떴는데, 사람이 읽는 문장으로 바뀌었습니다). 당황하지 않고 다시 입력하시면 됩니다.

**숫자가 안 뜰 때 — 두 가지 원인, 화면이 구분해서 알려줍니다**

- "아직 집계할 사용량이 없습니다" + "이 조직에 결합된 프로젝트가 없거나…" → **프로젝트를 결합 안 하셨거나(§4 확인) 방금 결합했지만 날짜가 아직 안 됐을 때**(§0)입니다.
- "적재 전입니다 — 사용량 뷰가 아직 준비되지 않았습니다. 0이 아닙니다." → 이건 프로젝트 결합과 무관하게 뒤쪽 시스템이 아직 준비되지 않았다는 별도 문구입니다. 이 문구가 뜨면 화면 문제가 아니라 준비 단계 문제이니 진행 중인 다른 화면(예: 성공/실패, 결합 목록)으로 넘어가 계속 시연하시면 됩니다.

**조직을 두 번 만든 것 같을 때**
같은 이름으로 "조직 만들기"를 다시 눌러도 조직이 두 개 생기지 않습니다 — 서버가 같은 이름이면 기존 조직을 그대로 돌려줍니다. 화면도 똑같이 "{조직 이름} 이(가) 준비됐습니다"가 뜨고 **같은 조직 홈**으로 들어갑니다. 걱정하지 마시고 그대로 "조직 홈으로"를 누르시면 됩니다.

**초대 링크를 잘못 보냈을 때**
조직 홈 아래 "대기 중인 초대" 목록에서 그 초대 옆 **취소** 버튼을 누르면 이미 보낸 링크도 즉시 못 쓰게 됩니다. 다시 "멤버 초대하기"로 새로 만들어 보내시면 됩니다.

- 멤버 초대: `createOrgInvitation`/`listOrgInvitations`/`revokeOrgInvitation`, 프론트 `InviteMemberForm`/`PendingInvitesPanel`(`OrgHomeClient.tsx`)
- 대시보드: `getOrgUsageSummary`(`v3/functions/src/index.ts:18684` 부근), 시각 게이트 판정 `resolveTeamUsageGate`/`clampWindowToGate`(`v3/functions/src/teamUsage.ts`) — 자세한 판정 로직은 `docs/org-analytics-demo-numbers-readiness-2026-09-06.md` ④절
- 5단 드릴다운: `OrgDrilldownView.tsx`/`orgDrilldownContract.ts`(#1497)

- 헤더 `/org` 링크 부재: `marblo-web/src/components/Header.tsx`에 `/org` 참조 0건(실측), 별도 개선 티켓 대상.
- 로그인 오류 메시지 사람화: `marblo-web/src/lib/authErrors.ts` + `messages/ko.json` `errorInvalidCredentials`.
- 조직 생성 멱등: `createOrganization`이 같은 `displayName`이면 기존 조직을 `{reused:true}`로 반환(`v3/functions/src/index.ts` 조직 생성 블록), 프론트는 `reused` 필드를 읽지 않고 항상 같은 성공 화면을 그린다(`orgOnboarding.ts` `parseCreateOrganizationData`) — 그래서 사용자에게는 "다시 눌러도 똑같이 성공"으로만 보인다.
