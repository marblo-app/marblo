# M2 · 탭 경험 + 승격

## 이번에 무엇을 만드는가

M1에서 만든 대화창 하나짜리 화면을 **보드가 보이는 워크스페이스**로 바꿉니다. 하는 일은 두 가지입니다. 먼저 지금 화면에 있는 아홉 개 탭이 각각 무엇을 하는 자리인지 한 칸씩 열어 확인합니다. 그다음 상단바의 버튼 하나로 **마블로 모드**로 넘어가, 지금까지 숨어 있던 다섯 개 탭을 엽니다.

이 레슨을 건너뛰면 M3에서 반드시 막힙니다. 첫 티켓이 어디까지 왔는지 보는 **보드**와, 머지된 기록이 쌓이는 **완료 이력**이 승격 전에는 화면에 없기 때문입니다. 짧지만 접지 않는 레슨입니다.

## 따라 하는 순서

### 1부: 지금 있는 아홉 탭을 한 칸씩 연다

대화 탭 위쪽 탭바를 왼쪽부터 순서대로 누릅니다. 각 탭에서 볼 것은 아래 한 줄씩입니다. 오래 머물지 마세요 — 지금은 "무엇이 어디에 있는가"만 외우면 됩니다.

| 탭 | 여기서 하는 일 | 한 번 확인할 것 |
| --- | --- | --- |
| **대화** | 마블로에게 말을 겁니다. 기본 화면입니다 | 입력칸과 아래쪽 진행 표시줄 |
| **시작하기** | 설치·인증·폴더·첫 티켓까지 남은 단계를 세는 체크리스트입니다 | *네 단계면 첫 티켓까지 갑니다* 와 진행률 |
| **가이드** | 제품 사용법 문서입니다. 비기너 모드와 마블로 모드를 오가는 법도 여기 있습니다 | 목차 |
| **코드** | 프로젝트 파일을 열고, 에이전트가 고친 변경점(diff)을 검토합니다 | `src/format.js` 를 한 번 열어 봅니다 |
| **마블로봇** | 지금 일하는 에이전트를 보고, 필요하면 끕니다 | 아직 비어 있는 것이 정상입니다 |
| **워크트리** | 각 작업이 격리된 브랜치와 그 머지 상태를 봅니다 | *워크트리가 없습니다* 가 정상입니다 |
| **사용량** | 이번 기간에 얼마나 썼는지 봅니다 | 기간 선택기 |
| **하네스** | 연결 센터입니다. 저장소(GitHub)·커넥터·Telegram/Slack 채널, 그리고 오케 CLI 로그인 상태 | **연결** 섹션과 **오케 CLI** 섹션 두 덩어리 |
| **설정** | 계정, 언어, 그리고 비기너 모드 ↔ 마블로 모드 전환 | *비기너 모드* 섹션 |

**여기서 보드를 찾지 마세요. 없습니다.** 대신 대화 탭 아래에 **일감 흐름** 이라는 가로 띠가 있고, 그 안에 *할 일 · 진행 중 · 완료* 세 칸이 있습니다. 이것이 비기너 모드의 축소판 보드입니다. 카드를 누르면 그 일감의 상세가 열리고, **바뀐 코드 보기** 를 누르면 코드 탭에서 그 변경점이 열립니다.

`src/format.js` 를 코드 탭에서 열어 두세요. 파일 맨 위 주석에 **"this file has no tests yet — a good first task to hand an agent"** 라고 적혀 있습니다. 이것이 M3의 재료입니다.

### 2부: 마블로 모드로 승격한다

1. **상단바 오른쪽의 `</>` 마블로 모드로 보기 버튼을 누릅니다.** 확인 창은 없습니다. 누르는 즉시 화면 전체가 바뀝니다.

2. **바뀐 화면의 구조를 확인합니다.** 왼쪽은 터미널 기둥입니다. 위가 **오케스트레이터**, 아래가 **에이전트** 터미널입니다. 오른쪽은 작업 탭 판입니다. 가운데 경계선을 끌어 좌우 너비를 바꿀 수 있습니다.

3. **새로 생긴 다섯 탭을 확인합니다.** 오른쪽 탭바에 **보드 · 병렬 작업 · 프로젝트 · 완료 이력 · 스토어** 가 추가됐습니다. 나머지 여덟은 이름도 자리도 그대로입니다 — 승격은 탭이 **늘어나는** 일이지 재배치되는 일이 아닙니다.

4. **보드 탭을 엽니다.** `TODO · CLAIMED · IN PROGRESS · REVIEW · BLOCKED · FAILED · DONE` 컬럼이 보입니다. 지금은 전부 비어 있습니다. M3에서 여기에 카드가 생깁니다.

5. **안내 카드(코치마크)가 뜨면 끝까지 넘겨 봅니다.** 보드 → 코드 → 에이전트 → 하네스 → 사용량 → 설정 순으로 각 탭이 무엇인지 한 줄씩 알려 줍니다. **건너뛰기** 를 눌러도 됩니다.

6. **되돌아가는 길을 확인만 하고 돌아오지는 않습니다.** 상단바에 **비기너 모드** 버튼이 생겼고, 설정 탭의 *비기너 모드* 섹션에도 같은 스위치가 있습니다. 되돌려도 진행 중인 에이전트는 그대로 계속 돕니다. 확인만 하고 마블로 모드에 머무릅니다.

## 화면에서 무엇을 보게 되는가

- 승격 직후 화면은 **왼쪽 터미널 · 가운데 경계선 · 오른쪽 작업 탭** 2페인(파일 트리를 켜면 3분할)입니다.
- 오른쪽 탭바가 **열세 개**가 됩니다. M1에서 보던 여덟 개(시작하기·가이드·코드·마블로봇·워크트리·사용량·하네스·설정)가 같은 이름, 같은 상대 순서로 그대로 있고 다섯이 끼어듭니다. **대화** 탭만 사라지는데, 그 자리를 왼쪽 오케스트레이터 터미널이 대신합니다.
- **보드** 탭에 칸반 컬럼이 서고, 컬럼마다 색이 다릅니다(TODO 회색, IN PROGRESS 파랑, REVIEW 보라, DONE 초록).
- 왼쪽 위 오케스트레이터 터미널에 프롬프트가 살아 있습니다. 여기가 M3에서 첫 요청을 보낼 자리입니다.

## 막힐 때

### 1. 비기너 화면에서 보드를 아무리 찾아도 없습니다

**없는 게 맞습니다.** 비기너 모드의 아홉 탭은 대화 · 시작하기 · 가이드 · 코드 · 마블로봇 · 워크트리 · 사용량 · 하네스 · 설정이고, 보드는 그 목록에 들어 있지 않습니다. 보드 · 병렬 작업 · 프로젝트 · 완료 이력 · 스토어 다섯은 **승격의 이유 그 자체**라서 일부러 빼 둔 것입니다.

그래서 이 다섯이 필요해지는 순간이 곧 승격할 순간입니다. 비기너 모드에서 보드를 찾아 헤매는 것이 구 커리큘럼에서 사람들이 가장 많이 멈추던 자리였습니다. 이 레슨을 넣은 이유가 그것입니다.

### 2. 승격하라는 안내 팝업이 안 뜹니다 — 기다려야 하나요?

기다릴 필요 없습니다. *마블로 모드로 전환해볼까요?* 팝업은 **티켓 몇 건을 끝냈거나, 첫 머지를 마쳤거나, 며칠째 쓰고 있을 때** 알아서 뜨는 제안일 뿐입니다. 첫날에는 안 뜨는 게 정상입니다.

**상단바의 `</>` 마블로 모드로 보기 버튼은 팝업과 무관하게 언제나 거기 있습니다.** 팝업을 기다리지 말고 그 버튼을 누르세요.

### 3. 승격했는데 보드가 아니라 "시작하기" 탭이 열렸습니다

정상입니다. 마블로는 **온보딩 체크리스트가 아직 안 끝났으면 시작하기 탭으로**, 다 끝났으면 보드로 착지합니다. 첫 실행이 안내를 놓치지 않게 하려는 설계입니다.

그대로 두고 오른쪽 탭바에서 **보드**를 직접 누르면 됩니다. 시작하기 탭 아래쪽의 *앱을 켤 때 이 탭으로 시작하지 않기* 를 켜면 다음부터는 보드로 바로 옵니다. 어느 쪽을 고르든 남은 단계는 시작하기 탭에 그대로 남습니다.

### 4. 안내 카드는 "에이전트"라는데 탭 이름은 "마블로봇"입니다

같은 탭입니다. 승격 직후 뜨는 안내 카드 중 하나가 아직 옛 제목(*에이전트 — 팀원 목록*)을 쓰고 있습니다. **탭바에 실제로 적힌 이름이 맞습니다 — 마블로봇입니다.** 마찬가지로 옛 자료에서 *퀵레인* 이라고 부르던 탭은 지금 **병렬 작업** 입니다.

이름이 안 나온 탭을 "없는 기능"으로 오해하지도 마세요. 안내 카드는 여섯 개 탭만 소개하고 끝납니다. 병렬 작업 · 프로젝트 · 완료 이력 · 스토어는 안내에 안 나올 뿐 멀쩡히 있습니다.

### 5. 되돌아갈 수 없을까 봐 승격이 망설여집니다

되돌아갈 수 있습니다. 마블로 모드 상단바의 **비기너 모드** 버튼, 또는 설정 탭의 *비기너 모드* 섹션에서 언제든 돌아갑니다. 화면 전체가 바뀌지만 **진행 중인 에이전트는 그대로 계속 돌아갑니다.** 작업이 끊기지 않습니다.

## 끝났는지 어떻게 아는가

**오른쪽 탭바에 "보드"가 있고, 눌렀을 때 TODO부터 DONE까지 칸반 컬럼이 보이면 M2는 끝입니다.**

보드가 안 보이면 아직 비기너 모드입니다. 상단바에서 `</>` **마블로 모드로 보기** 를 누르세요.
