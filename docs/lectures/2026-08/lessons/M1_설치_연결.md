# M1 · 설치·연결

## 이번에 무엇을 만드는가

마블로를 처음 켜서 **말을 걸 수 있는 상태**까지 갑니다. 끝나면 손에 남는 것은 셋입니다. 첫째, Claude 또는 Codex 중 **하나**가 로그인된 상태. 둘째, 마블로가 자동으로 만들어 연결해 준 연습용 프로젝트 폴더 `Marblo Sample`. 셋째, 그 폴더를 대상으로 지시를 받을 준비가 된 **대화창**. 이 셋이 갖춰지면 다음 레슨부터는 설치 이야기를 다시 하지 않습니다.

준비물은 하나뿐입니다. **Claude Pro/Max 또는 ChatGPT Plus/Pro(Codex) 구독 중 하나.** 카드도, 외부 API 키도, GitHub 계정도 이 레슨에는 필요 없습니다.

## 따라 하는 순서

1. **마블로를 켭니다.** 처음 켜면 언어를 고르는 창이 먼저 뜹니다. 한국어를 고르고 **계속**을 누릅니다. 나중에 설정에서 언제든 바꿀 수 있습니다.

2. **연결 화면에서 "한 번에 준비하기"를 찾습니다.** 첫 화면은 *하나만 연결하면 시작할 수 있어요* 라는 제목의 연결 게이트입니다. 그 안의 **모두 설치하고 자동 로그인** 버튼을 누릅니다. 마블로가 필요한 CLI를 대신 설치합니다.

3. **설치가 끝나기를 기다립니다.** 진행 표시가 `1/2 설치됨` 처럼 올라갑니다. 각 항목은 *대기 → 설치중 → 완료* 로 바뀝니다. 이 단계에서 손댈 것은 없습니다.

4. **가지고 있는 구독을 고릅니다.** 설치가 끝나면 *어떤 구독을 가지고 계세요?* 라는 화면이 뜹니다. 여기서 고르는 것은 "필요한 것"이 아니라 **이미 결제해 둔 것**입니다. Claude Pro/Max 를 쓰고 있으면 그것만, ChatGPT Plus/Pro 를 쓰고 있으면 그것만 고릅니다. 하나만 골라도 됩니다. 고른 뒤 **로그인 진행하기**를 누릅니다.

5. **브라우저에서 승인합니다.** 화면 아래쪽에 로그인용 터미널이 열리고 브라우저가 함께 뜹니다. 브라우저에서 계정을 확인하면 터미널이 자동으로 다음으로 넘어갑니다. 터미널에는 아무것도 입력하지 않습니다.

6. **폴더는 기다리기만 합니다.** 로그인이 끝나면 마블로가 *연습용 프로젝트를 준비하고 있어요* 라고 말하며 문서 폴더 아래에 `Marblo Sample` 을 만들고 자동으로 연결합니다. 몇 초면 끝납니다. 직접 폴더를 고를 필요가 없습니다.

7. **첫 요청 화면을 확인만 하고 이 레슨을 끝냅니다.** *무엇을 만들까요?* 라는 입력칸과 예시 세 개(README 를 읽고 시작 가이드를 정리해 줘 / 테스트가 없는 함수에 테스트를 붙여 줘 / 이 프로젝트 구조를 설명해 줘)가 보입니다. **여기서 아직 보내지 않습니다.** 첫 요청은 M3에서 끝까지 따라갑니다.

## 화면에서 무엇을 보게 되는가

- 연결이 끝나면 연결 카드가 **연결됐어요** 로 바뀌고, *준비 끝! 이제 무엇을 만들지 말씀해 주세요.* 라는 문장이 뜹니다.
- 화면 맨 위 상단바에 **폴더 이름이 표시됩니다.** 아직 폴더가 없으면 그 자리에 *폴더 없음* 이라고 적혀 있습니다. `Marblo Sample` 이 보이면 연결된 것입니다.
- 화면 가운데는 큰 대화창 하나입니다. 그 위 탭바에 **대화 · 시작하기 · 가이드 · 코드 · 마블로봇 · 워크트리 · 사용량 · 하네스 · 설정** 아홉 개가 있습니다. 보드는 여기 없습니다 — 정상입니다. M2에서 엽니다.
- 왼쪽 파일 트리에 `src/todo.js`, `src/format.js`, `src/demo.js`, `test/todo.test.js`, `README.md` 가 보입니다. 이것이 M3에서 쓸 재료입니다.

## 막힐 때

### 1. SuperGrok(Grok)만 로그인했는데 시작이 안 됩니다

구독 선택 화면에는 **SuperGrok** 도 항목으로 있습니다. 고를 수 있고 로그인도 정상적으로 끝납니다. 그런데 그것만으로는 다음으로 넘어가지 못합니다. 마블로가 이렇게 말합니다.

> 고르신 로그인은 다 끝났어요. 다만 시작하려면 Claude 또는 ChatGPT(Codex) 중 하나가 연결돼 있어야 합니다.

**지금 오케스트레이터를 띄울 수 있는 것은 Claude 와 Codex 둘뿐입니다.** 이 문장이 보이면 실패한 것이 아니라 아직 조건이 안 채워진 것입니다. 같은 화면에서 Claude Pro/Max 또는 ChatGPT Plus/Pro 를 추가로 골라 로그인을 한 번 더 진행하세요. 이미 로그인된 것은 자동으로 건너뜁니다.

### 2. 로그인은 됐다는데 실행이 안 됩니다 — "구독이 필요해요"

로그인 자체는 계정 확인일 뿐이고, 실제로 CLI를 돌리려면 그 계정에 **쓸 수 있는 구독이나 크레딧**이 있어야 합니다. 무료 계정으로 로그인하면 여기서 걸립니다. 마블로는 원인을 두 갈래로 나눠 말합니다.

- **구독이 필요해요** — 벤더가 구독·크레딧이 없다고 명확히 답한 경우입니다. **요금제 보기** 버튼으로 요금제 페이지를 열고, **로그인한 것과 같은 계정으로** 결제한 뒤 돌아와 **이미 구독했어요 · 다시 확인**을 누르면 그 자리에서 이어집니다.
- **인증은 됐지만 실행이 안 돼요** — 사용 한도에 걸렸거나, 다시 로그인하라고 하거나, 원인이 불분명한 경우입니다. 이때는 구독 문제로 단정하지 말고 화면의 **실행했을 때 나온 메시지 보기**를 눌러 원문을 확인하세요. 한도 문제면 시간이 지난 뒤 **다시 확인**만 누르면 됩니다.

계정이 두 개 있는 분들이 가장 많이 걸리는 자리입니다. 결제한 계정과 로그인한 계정이 같은지 먼저 보세요.

### 3. 브라우저 승인 창이 안 뜹니다

로그인 터미널은 떴는데 브라우저가 열리지 않는 경우가 있습니다. 화면에 이미 답이 적혀 있습니다.

> 브라우저가 안 열리면, 아래 창에 나온 주소를 복사해 직접 열어도 됩니다.

터미널 출력에 `https://` 로 시작하는 주소가 한 줄 있습니다. 그것을 복사해 브라우저 주소창에 직접 붙여 넣으면 같은 승인 화면이 뜹니다. 승인이 끝나면 터미널이 알아서 다음으로 넘어갑니다.

### 4. 원클릭 설치가 실패했습니다

권한 문제 등으로 자동 설치가 막히면 *원클릭 설치가 실패했어요* 화면이 뜨고, **그 자리에 붙여 넣을 명령이 그대로 인쇄됩니다.** 그 명령을 터미널에 붙여 넣어 직접 설치한 뒤 **다시 시도**를 누르세요. 마블로가 설치 상태를 다시 확인하고 로그인 단계로 넘어갑니다. 두 개 중 하나만 실패했다면 성공한 것으로 계속 진행되므로, 실패 표시가 있다고 처음부터 다시 하지 않아도 됩니다.

### 5. 연습용 폴더가 안 만들어졌습니다

*예제 폴더를 만들지 못했어요* 가 뜨면 상단의 **내 폴더 열기**로 직접 폴더를 고르면 됩니다. 이때 **빈 폴더보다 파일이 있는 폴더**를 고르세요. 빈 폴더를 연결하면 화면은 열리지만 첫 지시가 아무 결과도 못 냅니다 — 읽을 README 가 없으니까요.

이미 `Marblo Sample` 폴더가 있고 그 안에 내가 만든 파일이 들어 있다면, 마블로는 **한 바이트도 덮어쓰지 않고** 그 폴더를 그대로 재사용합니다. 내 작업이 지워질 걱정은 하지 않아도 됩니다.

## 끝났는지 어떻게 아는가

**상단바에 `Marblo Sample`(또는 내가 고른 폴더 이름)이 보이고, 대화 탭 가운데에 "무엇을 만들까요?" 입력칸이 떠 있으면 M1은 끝입니다.**

상단바에 아직 *폴더 없음* 이 보이거나 연결 카드가 남아 있으면 6단계와 4단계로 각각 돌아가세요.
