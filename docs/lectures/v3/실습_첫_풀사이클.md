# 실습: 첫 풀사이클 체험

> 모듈 1 · 실습 · 약 15분
> 관련: [[1-5_첫_풀사이클_체험]] | [[1-4_환경설정_MCP_Hook]]

---

## 실습 목표

마블로 v3를 사용해서 간단한 Hello World API 프로젝트를 처음부터 끝까지 한 바퀴 돌려봅니다.
핵심 슬래시 스킬 3개(`/tf-plan`, `/tf-start`, `/tf-review`)의 흐름을 체득합니다.

---

## 사전 준비 체크리스트

시작하기 전에 다음을 확인하세요:

- [ ] 마블로 v3 앱 실행 중
- [ ] 프로젝트 생성 또는 선택 완료
- [ ] 오케스트레이터 터미널에 Claude Code 실행 중
- [ ] MCP 연결 확인 (아무 MCP 도구 호출 가능)

---

## Step 1: 프로젝트 기획 (`/tf-plan`)

**(실습)**

1. 오케스트레이터 터미널에서 입력:
   ```
   /tf-plan Hello World API
   ```

2. Claude Code가 소크라틱 질문을 합니다. 다음과 같이 답변:
   ```
   간단한 FastAPI Hello World API를 만들어줘.
   - GET /hello → "Hello, World!" 반환
   - GET /hello/{name} → "Hello, {name}!" 반환
   - pytest 테스트 포함
   - 별도 인증 불필요
   ```

3. Claude Code가 PRD를 생성하고 태스크를 분해합니다.

4. 태스크 목록을 확인합니다:
   ```
   예상 태스크:
   TASK-001: FastAPI 프로젝트 초기 설정 (backend)
   TASK-002: /hello 엔드포인트 구현 (backend, depends_on: TASK-001)
   TASK-003: /hello/{name} 엔드포인트 구현 (backend, depends_on: TASK-001)
   TASK-004: pytest 테스트 작성 (test, depends_on: TASK-002, TASK-003)
   ```

5. "이대로 진행할까요?"라고 물으면 **확인**합니다.

화면: 칸반 보드에 아직 카드 없음 → /tf-plan 후에도 아직 없음 (기획 단계이므로)

---

## Step 2: 태스크 생성 + 에이전트 스폰 (`/tf-start`)

**(실습)**

1. 기획이 끝나면 오케스트레이터 터미널에서:
   ```
   /tf-start
   ```
   또는 기획 흐름에서 이어서 "진행해줘"

2. **관찰 포인트 (칸반 보드):**
   - TODO 컬럼에 카드 4개가 나타나는지 확인
   - 각 카드에 역할(backend/test) 라벨이 있는지 확인

3. **관찰 포인트 (터미널):**
   - "Agent spawned successfully!" 메시지 확인
   - 새 터미널 탭이 추가되는지 확인

4. 에이전트 터미널 탭을 클릭해서 작업 상황을 관찰합니다.

---

## Step 3: 실시간 관찰

**(실습)**

에이전트가 작업하는 동안 다음을 관찰하세요:

**칸반 보드 변화:**
```
시작: TODO에 4개
  ↓ (에이전트가 claim)
중간: CLAIMED 1개, TODO 3개
  ↓ (작업 시작)
진행: IN_PROGRESS 1개, TODO 3개
  ↓ (작업 완료)
리뷰: REVIEW 1개, TODO 2개 (의존성 해소된 것만 이동)
  ↓ (반복)
최종: REVIEW 3-4개 (전부 리뷰 대기)
```

**에이전트 터미널:**
- `claim_task` 호출 → "Successfully claimed task"
- `update_task_status` → "IN_PROGRESS"
- 파일 생성/수정 진행
- `add_activity` → 진행 기록
- `submit_for_review` → "REVIEW"

> 참고: 에이전트가 작업하는 데 보통 2-5분 정도 걸립니다.
> 칸반 보드를 계속 지켜보면서 카드가 이동하는 모습을 관찰하세요.

---

## Step 4: 리뷰 + 완료 (`/tf-review`)

**(실습)**

1. REVIEW 컬럼에 카드가 쌓이면, 오케스트레이터 터미널에서:
   ```
   /tf-review
   ```

2. 각 태스크를 검토합니다:
   - 활동 로그 확인 (어떤 파일을 만들었는지)
   - 코드가 합리적인지 확인
   - **Approve** 또는 **Reject** 선택

3. Approve하면 카드가 DONE으로 이동합니다.

4. 전부 Approve하면 **프로젝트 완료!**

---

## 결과 확인

**(실습)**

1. 칸반 보드: 모든 카드가 DONE 컬럼에 있는지 확인
2. 생성된 코드 확인 (Code 탭 또는 VS Code):
   ```
   project/
   ├── main.py          ← FastAPI 앱
   ├── requirements.txt ← 의존성
   └── test_main.py     ← pytest 테스트
   ```
3. 테스트 실행:
   ```bash
   pip install -r requirements.txt
   pytest test_main.py -v
   ```
4. API 실행:
   ```bash
   uvicorn main:app --reload
   # 브라우저에서 http://localhost:8000/hello 확인
   # http://localhost:8000/hello/Marblo 확인
   ```

## 체크리스트

실습 완료 여부를 확인하세요:

- [ ] `/tf-plan`으로 PRD + 태스크 분해 완료
- [ ] `/tf-start`로 태스크 생성 + 에이전트 스폰
- [ ] 칸반 보드에서 카드 이동 관찰 (TODO → CLAIMED → IN_PROGRESS → REVIEW)
- [ ] `/tf-review`로 리뷰 → DONE
- [ ] 생성된 코드 실행 확인

## 트러블슈팅

| 문제 | 해결 |
|------|------|
| MCP 도구 호출 실패 | Firebase 설정 확인, 앱 재시작 |
| 에이전트가 스폰되지 않음 | Bridge Server 포트 확인, 앱 재시작 |
| 카드가 안 움직임 | Firestore 연결 확인, 네트워크 확인 |
| 에이전트가 작업 중 멈춤 | 에이전트 터미널 탭에서 상태 확인, `/compact` 시도 |
| REVIEW 후 DONE으로 안 바뀜 | `update_task_status` 수동 호출 시도 |
