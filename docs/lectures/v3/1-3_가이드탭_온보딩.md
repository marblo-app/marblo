# 가이드 탭 온보딩 — 처음 켰을 때 길 찾기

> 모듈 1 · 섹션 1-3 · 약 20분
> 관련: [[1-2_마블로_한바퀴_탭투어]] | [[1-4_큰그림_파이프라인]]

---

## 이 강의에서 다루는 것

- **학습목표:** 첫 실행 시 표시되는 가이드 탭으로 스스로 다음 행동을 찾을 수 있다.
- **시연할 마블로 화면·기능:** 가이드 탭(GuideTab)의 8개 섹션 전체.
- **진행할 프로젝트 단계:** —
- **핵심 메시지:** "막히면 **가이드 탭**으로 돌아오면 된다."

---

## 도입 — 첫 실행 화면 (2분)

> 화면: 마블로를 처음 켰을 때 — 가이드 탭이 기본으로 열린 모습

새 도구를 처음 켜면 가장 막막한 게 "뭐부터 하지?"죠.
마블로는 그 막막함을 줄이려고, 첫 화면을 **가이드 탭**으로 띄웁니다.

가이드 탭은 매뉴얼을 따로 찾을 필요 없이,
"마블로란 무엇인지"부터 "다음에 뭘 할지"까지 한 화면에 정리해둔 온보딩 허브입니다.
지금부터 위에서 아래로, **8개 섹션**을 순서대로 훑겠습니다.

---

## 본문 — 가이드 탭 8개 섹션

### 1. Marblo란 (2분)

> 화면: 가이드 탭 — "1. Marblo란" 섹션

맨 위 섹션은 마블로가 무엇인지 한 문단으로 설명합니다.
1-1에서 배운 그대로예요 — 오케스트레이터가 자연어 요청을 태스크로 쪼개고,
역할별 에이전트가 칸반 보드를 공유하며 자율적으로 일하는 워크스페이스.

"내가 지금 켠 이 앱이 뭘 하는 도구인지" 한 번 더 못 박는 섹션입니다.

### 2. 시작하기 — 프로젝트 만들고 오케스트레이터 띄우기 (3분)

> 화면: 가이드 탭 — "2. 시작하기" 섹션

가장 실용적인 섹션입니다. 첫 행동의 순서를 알려줘요:

1. 작업할 **프로젝트 폴더/리포를 연결**한다.
2. 하단 **오케스트레이터**에 자연어로 요청한다.
3. `/tf-start` 또는 `/tf-analyze`로 흐름을 시작한다.

이 세 줄이 사실상 마블로 사용의 시작과 끝입니다.
(실제 연결과 첫 요청은 모듈 2·3에서 직접 해봅니다.)

### 3. TaskForce 슬래시 커맨드 (3분)

> 화면: 가이드 탭 — "3. TaskForce 슬래시 커맨드" 섹션

`/tf-*` 슬래시 커맨드 목록입니다.
이 커맨드들은 마블로 설치 시 사용자 환경에 **자동으로 깔립니다.**

자주 쓰는 것만 추리면:

| 커맨드                    | 하는 일                                     |
| ------------------------- | ------------------------------------------- |
| `/tf-start`               | 작업 시작 — 분석부터 스폰까지               |
| `/tf-analyze`             | 요구사항 분석 (컴포넌트·역할·의존성 파악)   |
| `/tf-create-tasks`        | 분석 결과를 Marblo MCP에 태스크로 일괄 생성 |
| `/tf-spawn-agents`        | 필요한 역할의 에이전트 자동 스폰            |
| `/tf-status`              | 전체 태스크 현황 조회                       |
| `/tf-review`              | REVIEW 상태 태스크 검토 후 DONE 처리        |
| `/tf-add`                 | 진행 중 새 태스크 추가 / 우선순위·설명 수정 |
| `/tf-fix`                 | FAILED / BLOCKED 태스크 진단·복구           |
| `/tf-ralph`               | Ralph 패턴으로 반복 작업 일괄 처리          |
| `/tf-resume` · `/tf-sync` | 세션 재개 / 상태 동기화                     |
| `/tf-guide`               | TaskForce 워크플로우 사용 가이드            |

여기서 외울 건 없습니다. 오케 패널에서 `/`만 누르면 이 목록이 그대로 뜨거든요.
"이런 명령들이 있구나" 정도만 눈에 익히면 됩니다.

### 4. Marblo MCP — 오케스트레이터 ↔ 칸반 ↔ 에이전트 (2분)

> 화면: 가이드 탭 — "4. Marblo MCP" 섹션

슬래시 커맨드 아래에서 실제로 일하는 엔진이 **Marblo MCP**입니다.
이 MCP 서버는 설치 시 사용자 Claude Code의 글로벌 설정에 **자동으로 등록**됩니다.

역할은 오케스트레이터 ↔ 칸반 보드 ↔ 에이전트 사이의 다리예요.
에이전트가 태스크를 claim하고, 상태를 바꾸고, 진행을 기록하는 게 전부 이 MCP를 통합니다.
(MCP의 내부 구조는 부록 A에서.)

### 5. 멀티윈도우 — 여러 프로젝트 동시 작업 (2분)

> 화면: 가이드 탭 — "5. 멀티윈도우" 섹션

프로젝트를 두 개 이상 동시에 굴리고 싶을 때를 위한 섹션입니다.
창을 여러 개 띄워 프로젝트별로 격리해 운영할 수 있습니다.
(실전 활용은 모듈 6·8에서.)

### 6. Harness 스토어 — 추천 스킬 / MCP 한 번에 설치 (2분)

> 화면: 가이드 탭 — "6. Harness 스토어" 섹션

1-2에서 본 하네스 탭으로 가는 안내입니다.
단축키는 **Cmd/Ctrl + Shift + H**.
추가 스킬과 MCP(예: context7 / filesystem / github MCP)를 카드 클릭으로 설치·제거합니다.
필수 항목은 이미 글로벌에 깔려 있고, 추천/MCP 카테고리는 선택입니다.

### 7. 텔레그램 채널 연결 — 알림 / 제어를 텔레그램으로 (2분)

> 화면: 가이드 탭 — "7. 텔레그램 채널 연결" 섹션

텔레그램 봇을 연결하면, 자리를 비워도 에이전트 진행 상황을 **알림으로 받고**,
텔레그램에서 간단한 제어까지 할 수 있습니다.
가이드에 봇 생성 → 토큰 발급 → 연결 순서가 적혀 있습니다.
(필수는 아니고, 장시간 작업을 돌릴 때 유용합니다.)

### 8. 다음 단계 (2분)

> 화면: 가이드 탭 — "8. 다음 단계" 섹션

마지막 섹션은 "이제 뭘 하면 되는가"를 짚어줍니다.
프로젝트를 연결하고, 오케에 첫 요청을 던지고,
하네스에서 추가 스킬·MCP를 깔아 워크플로우를 확장하는 흐름이죠.

이 강의의 다음 모듈들이 정확히 이 순서를 따라갑니다.

---

## "막히면 여기로" — 회귀 패턴 (1분)

가이드 탭의 진짜 가치는 **돌아올 곳**이라는 데 있습니다.

- 슬래시 명령이 기억 안 나면 → 3번 섹션
- 단축키를 까먹었으면 → 6번 섹션(⌘⇧H)
- "다음에 뭐 하지?" 싶으면 → 8번 섹션

새 기능을 만나 헷갈릴 때마다 가이드 탭으로 돌아오면,
대부분의 "어떻게 하지?"는 여기서 풀립니다.

---

## 정리 (1분)

1. 마블로는 첫 화면을 **가이드 탭**으로 띄워 막막함을 줄인다.
2. 8개 섹션 = Marblo란 / 시작하기 / 슬래시 커맨드 / Marblo MCP / 멀티윈도우 / Harness(⌘⇧H) / 텔레그램 / 다음 단계.
3. **막히면 가이드 탭으로 돌아오면 된다.**

다음 섹션에서는 지금까지 본 탭과 기능들이 하나의 흐름으로 어떻게 이어지는지,
**오케 → 보드 → 레인 → 워크트리 → 머지**의 큰 그림을 그려보겠습니다.
