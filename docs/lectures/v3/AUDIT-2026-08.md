## 순서 자체가 어긋난 곳

강의 순서: 탭투어(가이드가 첫 화면) → 가이드 8섹션 → 파이프라인 → **하네스 스토어에서 스킬/MCP/CLI 설치** → CLI 인증 → 설정 BYOK → 폴더 연결 → 하단 오케.

지금 신규 설치:

1. **비기너 셸**이 뜬다 (`App.tsx:547-555`). 첫 화면은 가이드가 아니라 **대화** + 연결 게이트.
2. CLI는 **한 번에 준비하기 / 모두 설치하고 자동 로그인** (`beginner.ts:48-51`) 또는 엑스퍼트 **시작하기** 탭 4단계 (`onboarding.startHere.subtitle` `onboarding.ts:478-479`).
3. 폴더 연결은 비기너 탑바 **내 폴더 열기** (`beginner.ts:9`) 또는 시작하기 탭이지, 2-4의 "하단 오케가 이미 떠 있는 다음 단계"가 아니다.
4. 하네스 탭은 연결 센터다. 스킬·MCP 원클릭은 **스토어** (`harness.ts:180-181`).
5. 보드/레인은 비기너에 없다. 모듈 3을 비기너 상태로 따라가면 탭이 없다. 강의는 승격(**마블로 모드로 보기**, `beginner.ts:12`)을 한 번도 가르치지 않는다.

**모듈 1·2 촬영 순서를 통째로 다시 짜야 한다.** 본편 3~8도 "하단 오케 / 레인 탭에서 에이전트 관찰"을 전제로 하므로 레이아웃 컷은 같이 다시 찍어야 한다.

`V3_촬영가이드.md`는 2026-04 커리큘럼(Board/Code/Agents/Flows 4탭, Gemini, 모듈 번호가 HOME과 다름)이라 **이 파일로 찍으면 안 된다.**
