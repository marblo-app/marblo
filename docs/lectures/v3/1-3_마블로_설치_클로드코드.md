# 마블로 설치 + Claude Code 필수 사용법

## 도입 (2분)

자, 이제 직접 설치해봅시다.

이전 섹션에서 마블로의 핵심 기능 6가지를 봤죠?
이제 그 앱을 여러분 컴퓨터에 설치하고,
마블로의 엔진인 Claude Code도 함께 세팅하겠습니다.

v1 때는 설치가 좀 고통스러웠습니다.
Docker Desktop 설치하고, docker-compose.yml 작성하고,
FastAPI 서버, Next.js 프론트, 사이드카 터미널 서버... 컨테이너 5개를 띄워야 했어요.

v3는 다릅니다.

## 본문

### 마블로 설치 — DMG 더블클릭 (5분)

화면: 마블로 공식 사이트 다운로드 페이지

**(실습) 마블로 설치**

**Step 1: 다운로드**

마블로 공식 사이트에서 DMG 파일을 다운로드합니다.
macOS, Windows, Linux 모두 지원합니다.

```
macOS:   Marblo-x.x.x-arm64.dmg (Apple Silicon)
         Marblo-x.x.x-x64.dmg (Intel)
Windows: Marblo-Setup-x.x.x.exe
Linux:   Marblo-x.x.x.AppImage
```

화면: DMG 파일 더블클릭 → 앱 아이콘을 Applications로 드래그

**Step 2: 설치**

macOS에서는 DMG 더블클릭 → 앱 아이콘을 Applications 폴더로 드래그.
끝입니다. 진짜 이게 끝이에요.

v1과 비교:
```
v1 설치 과정:
  1. Docker Desktop 설치 (10분)
  2. 저장소 clone
  3. .env 파일 생성
  4. docker compose up -d --build (5분)
  5. 5개 컨테이너가 정상적으로 뜨는지 확인
  6. localhost:3001 접속 확인
  → 총 20-30분

v3 설치 과정:
  1. DMG 다운로드
  2. 더블클릭 → Applications로 드래그
  → 총 2분
```

화면: 마블로 앱 첫 실행 화면

**Step 3: 첫 실행**

앱을 처음 실행하면 로그인 화면이 나옵니다.
Google, GitHub, 이메일 — 원하는 방식으로 로그인하시면 됩니다.
Firebase Auth 기반이라 가입도 간단합니다.

### Firebase 프로젝트 연결 (5분)

화면: 마블로 앱 설정 화면 — Firebase 연결

마블로는 Firebase Firestore를 데이터베이스로 사용합니다.
칸반 보드의 태스크, 에이전트 상태, 플로우 데이터 — 전부 Firestore에 저장됩니다.

**(실습) Firebase 연결**

처음 사용하시는 분은 마블로가 제공하는 공유 Firebase 프로젝트를 쓸 수 있습니다.
나만의 프로젝트를 쓰고 싶으면:

**1. Firebase 콘솔에서 프로젝트 생성**
```
https://console.firebase.google.com/
→ 프로젝트 추가 → 이름 입력 → 계속
```

**2. Firestore Database 활성화**
```
Firebase 콘솔 → Firestore Database → 데이터베이스 만들기
→ 테스트 모드에서 시작 → 위치 선택 (asia-northeast3 권장)
```

**3. 웹 앱 등록**
```
프로젝트 설정 → 내 앱 → 웹 앱 추가
→ 생성된 설정값 복사:
  - API Key
  - Auth Domain
  - Project ID
  - Storage Bucket
  - Messaging Sender ID
  - App ID
```

**4. 마블로 앱에서 연결**
```
마블로 → 설정 → Firebase 설정 → 위 값들 입력 → 연결 테스트 → 저장
```

5분이면 끝납니다. 한 번만 하면 돼요.

### Claude Code 설치 (5분)

화면: 터미널 — Claude Code 설치

마블로의 오케스트레이터와 에이전트는 내부적으로 Claude Code CLI를 사용합니다.
그래서 Claude Code가 반드시 설치되어 있어야 합니다.

**(실습) Claude Code 설치**

```bash
# Claude Code 설치 (macOS/Linux)
curl -fsSL https://claude.ai/install.sh | bash
```

설치 후 확인:
```bash
claude --version
```

화면: 터미널 — claude 명령어 실행 확인

처음 실행하면 Anthropic 계정 연동을 요청합니다.
지시에 따라 브라우저에서 로그인하면 됩니다.

> 참고: Claude Code를 사용하려면 Anthropic 유료 플랜(Pro 이상)이 필요합니다.
> Max 플랜을 사용하시면 하루 사용량이 훨씬 넉넉해서 에이전트 여러 개를 돌리기 좋습니다.

### Claude Code 핵심 명령어 (5분)

화면: 터미널 — Claude Code 실행 중

Claude Code를 모르시는 분도 계시니까, 핵심 명령어 네 가지만 짚고 가겠습니다.

**1. `/compact` — 컨텍스트 정리**
```
사용 중 터미널에서: /compact
```
대화가 길어지면 토큰이 쌓여서 비용도 늘고, 응답도 느려집니다.
`/compact`를 치면 이전 대화를 요약해서 압축합니다.
에이전트가 오래 작업할 때 특히 중요합니다.

**2. `/cost` — 비용 확인**
```
사용 중 터미널에서: /cost
```
현재 세션에서 얼마나 썼는지 보여줍니다.
에이전트 3개를 동시에 돌리면 비용이 빨리 올라가니까, 수시로 확인하세요.

**3. `/clear` — 대화 초기화**
```
사용 중 터미널에서: /clear
```
현재 대화를 완전히 초기화합니다.
새 작업을 시작할 때 사용합니다.

**4. `/model` — 모델 변경**
```
사용 중 터미널에서: /model
```
Claude Sonnet, Opus 등 모델을 전환할 수 있습니다.
비용 민감한 작업은 Sonnet, 복잡한 작업은 Opus로 전환하면 좋습니다.

### Claude Code 권한 모드 (3분)

화면: 슬라이드 — 권한 모드 3가지

Claude Code에는 세 가지 권한 모드가 있습니다.
에이전트를 돌릴 때 이걸 이해하는 게 중요합니다.

**1. Normal (기본)**
```
파일 읽기: O
파일 쓰기: 매번 확인
명령어 실행: 매번 확인
```
가장 안전하지만, 에이전트가 작업할 때마다 확인을 요청합니다.
에이전트 자율 작업에는 맞지 않습니다.

**2. Auto-Accept (자동 허용)**
```
CLI 실행: claude --dangerously-skip-permissions
파일 읽기/쓰기: 자동 허용
명령어 실행: 자동 허용
```
마블로의 에이전트들은 이 모드로 실행됩니다.
`--dangerously-skip-permissions` 플래그가 자동으로 붙어요.
그래야 에이전트가 자율적으로 코딩하고, 파일 만들고, 테스트 돌릴 수 있으니까요.

**3. Plan 모드**
```
CLI 실행: claude --plan
분석만 함: 코드 변경 없이 계획만 출력
```
코드를 수정하지 않고 분석만 합니다.
"이거 어떻게 하면 좋을지 계획만 세워줘" 할 때 사용합니다.

> 마블로에서 에이전트가 `--dangerously-skip-permissions`로 실행되는 코드는
> `electron/agent-config.ts`에 있습니다:
> ```typescript
> case 'claude':
>   return {
>     command: 'claude',
>     args: ['--dangerously-skip-permissions', '--mcp-config', mcpConfigPath],
>     env,
>   };
> ```

## 정리 (2분)

화면: 체크리스트 슬라이드

설치 완료 체크리스트:

- [ ] 마블로 v3 앱 설치 및 실행
- [ ] Firebase 프로젝트 연결 (또는 공유 프로젝트 사용)
- [ ] Claude Code 설치 (`claude --version` 확인)
- [ ] Anthropic 계정 연동 완료

Claude Code 핵심 명령어:
- `/compact`: 컨텍스트 압축 (토큰 절약)
- `/cost`: 비용 확인
- `/clear`: 대화 초기화
- `/model`: 모델 전환

권한 모드:
- 에이전트는 **Auto-Accept** 모드 (`--dangerously-skip-permissions`)
- 오케스트레이터도 Auto-Accept — 에이전트 스폰, 태스크 관리를 자율적으로

다음 섹션에서는 MCP 연결, 슬래시 스킬 설치, Hook 설정을 하겠습니다.
이 세 가지가 세팅되면 에이전트를 돌릴 준비가 완료됩니다.
