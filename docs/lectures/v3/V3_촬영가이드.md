## 촬영 순서

**원칙: 실전(라이브 빌딩)을 먼저 찍고, 설명은 나중에.**

- 라이브 빌딩을 먼저 찍어야 "나중에 이렇게 됩니다" 참조 가능
- 에러/삽질을 미리 겪어서 세팅 모듈에서 주의점을 자연스럽게 언급

```
Day 1: 모듈 4 — 메인 프로젝트 라이브 빌딩 (4시간) ← 가장 중요
  ├─ 가장 길고 집중력 필요
  ├─ 깨끗한 환경에서 시작 (DB 초기화, Git 클린)
  ├─ /tf-plan → /tf-create-tasks → /tf-spawn-agents → Sprint별 촬영
  ├─ 상황별 슬래시 스킬 자연스럽게 사용
  └─ 에러가 나면? "실제로 이런 에러가 납니다" → 교육 포인트로 활용

Day 2: 모듈 3 + 5 — 워밍업 프로젝트 + 멀티모델 (3.5시간)
  ├─ 모듈 3: 날씨 대시보드 워밍업 (1.5시간)
  │   ├─ /tf-plan → /tf-start → /tf-review 핵심 흐름만
  │   └─ 프론트+백엔드 왕복 체크
  ├─ 모듈 5: 멀티모델 에이전트 실습 (2시간)
  │   ├─ Claude + Gemini + Codex 에이전트 동시 스폰
  │   ├─ 마블로 앱에서 3개 모델 에이전트 동시 작업 관찰
  │   └─ 오케스트레이터 패널 시연

Day 3: 모듈 1 — 소개 + 설치 + 첫 체험 (2시간)
  ├─ 마블로 v3 소개 + v1 비교 (슬라이드)
  ├─ ⭐ 마블로 핵심 기능 소개 (25분):
  │   - STDIN 자동 프롬프트 주입 (node-pty → Claude Code)
  │   - 슬래시 메뉴 (/ 입력 → 명령어 팝업 → 프롬프트 주입)
  │   - 올인원 워크스페이스 (Board/Code/Agents/Flows 4탭)
  │   - 통합 터미널 패널 (칸반+터미널 한 화면)
  │   - 멀티모델 지원 (Claude+Gemini+GPT+Custom)
  │   - MCP 브릿지 서버 (에이전트→칸반 실시간 연동)
  ├─ 설치 데모 (깨끗한 환경에서)
  └─ 첫 풀사이클: /tf-plan → /tf-start → /tf-review

Day 4: 모듈 2 — 시스템 구조 + 스킬 설계 + 플로우 (2시간)
  ├─ MCP 개념 + 아키텍처 슬라이드
  ├─ 코드 뜯어보기: mcp-server, agent-manager, bridge-server
  ├─ 에이전트 스킬 파일 편집 → 행동 변화 관찰
  └─ 플로우 에디터 기초 실습

Day 5: 모듈 6, 7, 8 — 배포 + 랜딩 + 마무리 (4시간)
  ├─ 모듈 6: GCP 배포 + 크론잡 (1.5시간)
  ├─ 모듈 7: SaaS 랜딩페이지 + Stitch MCP 프론트 (1시간)
  └─ 모듈 8: 운영 패턴 + /tf-ralph + 마무리 (1.5시간)
```

## 촬영 방식 (모듈별)

### 모듈 1: 마블로 소개 + 설치 + 첫 체험

| 섹션                       | 화면 구성               | 방식                                                     |
| -------------------------- | ----------------------- | -------------------------------------------------------- |
| 1-1 왜 에이전트 군단인가   | 슬라이드                | JIRA 비교표, Agent Teams 개념도                          |
| 1-1+ 마블로 핵심 기능 데모 | 마블로 앱 풀스크린      | STDIN 주입, 슬래시 메뉴, 칸반+터미널, 플로우 에디터 시연 |
| 1-2 설치 + Claude Code     | 터미널 전체             | 앱 설치 + Claude Code 설치                               |
| 1-3 환경 설정              | 터미널 + 에디터 분할    | MCP, 슬래시 스킬, Hook 설정                              |
| 1-4 첫 풀사이클            | 마블로 앱 (칸반+터미널) | /tf-plan → /tf-start → /tf-review                        |

### 모듈 2: 시스템 구조 + 스킬 설계

| 섹션              | 화면 구성            | 방식                             |
| ----------------- | -------------------- | -------------------------------- |
| 2-1 MCP 개념      | 슬라이드             | MCP 통신 다이어그램              |
| 2-2 아키텍처      | 에디터 + 터미널      | 코드 열어보며 설명               |
| 2-3 상태 머신     | 슬라이드 → 마블로 앱 | 상태 다이어그램 + 실제 전환 시연 |

## 편집 원칙

**최소 편집** — 자연스러운 흐름이 코딩 강의에 맞음

| 항목                      | 처리                                |
| ------------------------- | ----------------------------------- |
| 설치/빌드 대기 (30초+)    | 타임랩스 or "잠시 후..." 컷         |
| 에이전트 코딩 대기 (1분+) | 2배속 + 칸반 보드 변화 강조         |
| 타이핑 실수               | 그냥 두기 (자연스러움)              |
| 긴 에러 디버깅            | 핵심 원인+해결만 남기고 컷          |
| 챕터 마커                 | 각 섹션마다 삽입                    |
| 중요 코드                 | OBS 줌 or 후편집 확대               |
| 에이전트 3개 동시 작업    | 마블로 Agents 탭에서 상태 변화 캡처 |
