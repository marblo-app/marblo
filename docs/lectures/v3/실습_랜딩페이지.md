# 실습: Stitch MCP로 SaaS 랜딩페이지 만들기

> 모듈 7 · 실습 · [[7-1_랜딩페이지_Stitch]] 보충 자료
> 관련: [[7-1_랜딩페이지_Stitch]] | [[7-2_런칭_체크리스트]] | [[8-1_일상_운영패턴]]

---

## 실습 목표

이 실습을 완료하면 다음을 할 수 있습니다:
- Stitch MCP를 Claude Code에 연결하여 디자인 → 코드 변환 파이프라인 구축
- 마블로 에이전트를 활용해 SaaS 랜딩페이지의 핵심 섹션 자동 생성
- Next.js + Tailwind CSS 기반의 반응형 랜딩페이지를 실제로 배포

## 사전 요구사항

- [ ] 마블로 v3 앱이 설치되어 있어야 합니다
- [ ] Claude Code CLI 인증 완료 (`claude login`)
- [ ] 모듈 4의 AI YouTube Insight 프로젝트가 있어야 합니다 (없으면 새 프로젝트로 대체 가능)
- [ ] Figma 계정 + Access Token (선택 — 없어도 진행 가능)
- [ ] Node.js 18+ 설치

---

## Step 1: 프로젝트 준비 (3분)

모듈 4에서 만든 프로젝트를 기반으로 작업합니다. 새 프로젝트로 시작해도 됩니다.

```bash
# 기존 프로젝트로 작업하는 경우
cd ~/projects/youtube-insight

# 새 프로젝트로 시작하는 경우
npx create-next-app@latest landing-demo --typescript --tailwind --app --src-dir
cd landing-demo
```

### 필요한 패키지 설치

```bash
# UI 컴포넌트 라이브러리
npx shadcn@latest init

# 애니메이션 라이브러리
npm install framer-motion

# 아이콘
npm install lucide-react

# SEO
npm install @next/third-parties
```

---

## Step 2: Stitch MCP 설정 (5분)

### 2-a: Stitch MCP 서버 설치

```bash
npm install -g @stitch-mcp/server
```

### 2-b: MCP 설정 파일 업데이트

프로젝트 루트에 `.mcp.json` 파일을 생성하거나 수정합니다:

```json
{
  "mcpServers": {
    "marblo": {
      "command": "node",
      "args": ["/path/to/marblo/mcp-server/dist/index.js"]
    },
    "stitch": {
      "command": "stitch-mcp",
      "args": ["--figma-token", "${FIGMA_ACCESS_TOKEN}"]
    }
  }
}
```

### 2-c: Figma Access Token (선택)

Figma 디자인 파일이 있는 경우:

1. Figma → Settings → Account
2. "Personal access tokens" → "Create a new personal access token"
3. 토큰 이름: `stitch-mcp`
4. 환경변수로 설정:

```bash
export FIGMA_ACCESS_TOKEN="figd_xxxxxxxxxxxx"
```

**Figma 없이 진행하는 경우:** Stitch MCP의 `generate_from_description` 모드를 사용합니다. 텍스트 설명만으로 컴포넌트를 생성하는 기능이에요.

### 2-d: 연결 확인

```bash
claude
# Claude Code 진입 후
/mcp
# marblo: connected
# stitch: connected
```

## Step 3: 마블로 프로젝트 생성 (2분)

1. 마블로 앱을 실행합니다
2. 좌측 사이드바 하단의 **"+"** 버튼 클릭
3. 프로젝트 설정:
   - **프로젝트명**: `youtube-insight-landing`
   - **프로젝트 경로**: `~/projects/youtube-insight` (또는 `~/projects/landing-demo`)
4. "Create" 클릭

화면: 빈 칸반 보드가 표시됩니다.


## Step 5: 에이전트로 랜딩페이지 빌드 (15분)

### 5-a: 오케스트레이터 실행

1. 마블로 앱에서 "Orchestrator" 버튼 클릭
2. 오케스트레이터 부팅 확인

### 5-b: 요구사항 입력

오케스트레이터 터미널에 다음을 입력합니다:

```
AI YouTube Insight SaaS의 랜딩페이지를 만들어줘.

필요한 섹션:
1. Hero 섹션 — "AI가 유튜브를 분석합니다" 헤드라인 + CTA 버튼 2개 (시작하기, 데모보기)
2. Features 섹션 — AI 요약, 트렌드 분석, 자동 리포트 3가지 기능
3. How It Works — 3단계 플로우 (URL 입력 → AI 분석 → 리포트 받기)
4. Pricing 섹션 — Free / Pro (29,000원) / Enterprise (문의) 3단계
5. CTA 섹션 — 최종 행동 유도
6. Footer — 링크, 소셜미디어, 법적 고지

기술:
- Next.js App Router + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion 애니메이션
- 반응형 (모바일 우선)

Stitch MCP를 사용해서 디자인 토큰 기반으로 컴포넌트를 생성해줘.
```

### 5-c: 태스크 생성 관찰

화면: 칸반 보드에 태스크가 자동 생성

오케스트레이터가 다음과 같이 태스크를 분해합니다:

```
TASK-001: HeroSection 컴포넌트 생성
TASK-002: FeaturesSection 컴포넌트 생성
TASK-003: HowItWorks 컴포넌트 생성
TASK-004: PricingSection 컴포넌트 생성
TASK-005: CTASection + Footer 컴포넌트 생성
TASK-006: 전체 페이지 조합 + 라우팅
TASK-007: SEO 메타태그 설정
```

### 5-d: 에이전트 작업 관찰

Agents 탭에서 에이전트의 작업을 실시간으로 관찰합니다:

**관찰 포인트:**
- Stitch MCP 호출 로그 (`stitch.generate_component`)
- 생성되는 파일 목록
- Tailwind 클래스 자동 적용
- Framer Motion 애니메이션 추가

### 6-c: 반응형 테스트

1. `F12` → Toggle Device Toolbar (`Ctrl+Shift+M` / `Cmd+Shift+M`)
2. 다음 디바이스에서 확인:
   - iPhone 14 Pro (390px)
   - iPad (768px)

**체크리스트:**

- [ ] Hero 텍스트가 모바일에서 읽기 좋은가?
- [ ] Features 카드가 모바일에서 세로로 쌓이는가?
- [ ] Pricing 카드가 모바일에서 스와이프/스크롤 가능한가?

```bash
gcloud run deploy youtube-insight-frontend \
```

## 트러블슈팅

### 문제: Stitch MCP가 "not connected"

```bash
# MCP 서버 직접 실행해서 확인
stitch-mcp --figma-token $FIGMA_ACCESS_TOKEN

# 오류 메시지 확인 후 대처
# "Invalid token" → Figma Access Token 재발급
# "Connection refused" → Figma API 상태 확인
```

### 문제: Framer Motion 빌드 에러

```bash
# framer-motion은 클라이언트 컴포넌트에서만 사용 가능
# 파일 상단에 "use client" 추가 필요
```

```tsx
// 파일 첫 줄에 반드시 추가
"use client";

import { motion } from "framer-motion";
```

### 문제: Tailwind 스타일이 적용 안 됨

```bash
# tailwind.config.ts의 content 경로 확인
cat tailwind.config.ts
```

```ts
// content에 landing 디렉토리가 포함되어 있어야 합니다
content: [
  "./src/**/*.{js,ts,jsx,tsx,mdx}",
]
```

### 문제: OG 이미지가 안 보임

- `public/og-image.png` 파일이 존재하는지 확인
- 이미지 크기: 1200x630px (권장)
- URL이 절대 경로인지 확인 (`https://your-domain.com/og-image.png`)
