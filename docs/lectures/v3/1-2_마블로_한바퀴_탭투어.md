# 마블로 한 바퀴 — 실제 탭 투어

> 모듈 1 · 섹션 1-2 · 약 25분
> 관련: [[1-1_왜_에이전트_팀인가]] | [[1-3_가이드탭_온보딩]]

---

## 이 강의에서 다루는 것

- **학습목표:** 현재 제품의 탭 구조와 각 탭의 역할을 머릿속에 지도화한다.
- **시연할 마블로 화면·기능:** 실제 탭바를 순서대로 — 가이드 · 보드 · 레인 · 코드 · 에이전트 · 사용량 · 워크트리 · 하네스 · 설정. 하단 오케스트레이터 PTY 패널과 레인 그리드 위치.
- **진행할 프로젝트 단계:** —
- **핵심 메시지:** "마블로 = **칸반 보드 + 에이전트 터미널 + 워크트리**가 한 화면에."

---

## 도입 (2분)

이전 섹션에서 "왜 에이전트 팀인가"를 이야기했습니다.
이번엔 그 팀을 운영하는 작업대 — 마블로 앱을 직접 열어 **한 바퀴 돌아보겠습니다.**

> 화면: 마블로 v3 앱 실행, 프로젝트가 열린 상태

슬라이드는 없습니다. 화면을 따라가면 됩니다.
상단에 탭바가 있고, 아래에는 오케스트레이터 터미널 패널이 깔려 있죠.
이 두 영역이 마블로의 뼈대입니다. 탭부터 하나씩 보겠습니다.

상단 탭바에는 **프로덕션 탭 9개**가 순서대로 있습니다:

> **가이드 · 보드 · 레인 · 코드 · 에이전트 · 사용량 · 워크트리 · 하네스 · 설정**

(이 9개가 정식 기능입니다. Flows · Missions · Deploy 같은 탭은 베타 기능이라 기본 빌드에선 숨겨져 있고, 모듈 8에서 미리보기로만 다룹니다.)

---

## 본문 — 탭바 한 바퀴

### 1. 가이드 탭 — 길을 잃으면 여기로 (2분)

> 화면: 가이드 탭(GuideTab)

처음 앱을 켜면 만나는 탭입니다.
"마블로란 무엇인가", "어떻게 시작하나", "슬래시 명령 목록", "단축키"까지
온보딩에 필요한 내용이 다 들어 있습니다.

지금은 "여기가 막힐 때 돌아오는 홈"이라는 것만 기억하세요.
가이드 탭의 8개 섹션은 **다음 레슨(1-3)**에서 통째로 살펴봅니다.

### 2. 보드 탭 — 칸반 보드 (3분)

> 화면: 보드 탭 — 칸반 보드 전체

여기가 모든 것의 중심입니다.
`TODO · CLAIMED · IN_PROGRESS · REVIEW · DONE` 컬럼이 있고
(+ 필요 시 `BLOCKED · FAILED`), 태스크 카드가 그 사이를 오갑니다.

JIRA와 다른 점은, 이 카드들이 사람이 아니라 **에이전트에 의해 자동으로 움직인다**는 겁니다.
에이전트가 태스크를 claim하면 TODO → CLAIMED, 작업을 시작하면 IN_PROGRESS,
끝나면 REVIEW로. 실시간 동기화라 상태가 바뀌면 보드에 곧장 반영됩니다.

각 카드에는 역할 배지(frontend/backend/test 등)와 의존성 정보가 붙습니다.

### 3. 레인 탭 — 에이전트별 작업대 (3분)

> 화면: 레인 탭(LanesTab) — 에이전트별 행(row)

레인 탭은 "어떤 에이전트가 지금 무엇을 하고 있는가"를 **행(레인) 단위**로 보여줍니다.
한 줄이 한 에이전트의 작업대예요.

각 레인 행에는:

- 모델 아이콘(예: 🟣 claude, Codex)
- 그 에이전트가 일하는 **워크트리 상태 pill**
- 터미널을 펼쳐 보는 **attach** 버튼

이 들어 있습니다. attach를 누르면 그 에이전트의 PTY가 열려서
실제로 코드를 짜는 과정을 들여다볼 수 있습니다.
(레인을 실전에서 쓰는 건 모듈 3·4에서.)

### 4. 코드 탭 — Monaco 에디터 (2분)

> 화면: 코드 탭 — 파일 트리 + 에디터 + diff

VS Code와 같은 Monaco Editor가 내장돼 있습니다.
왼쪽 파일 트리, 오른쪽 에디터.
에이전트가 만든 코드를 바로 확인하고, **diff로 변경 사항을 검토**할 수 있습니다.
리뷰할 때 VS Code를 따로 열 필요가 없어요.

### 5. 에이전트 탭 — 팀 대시보드 (2분)

> 화면: 에이전트 탭(AgentsTab) — 에이전트 카드들

현재 돌아가는 에이전트들의 상태를 한눈에 봅니다.
각 카드에 모델(Claude / Codex / Antigravity), 역할, 상태가 표시됩니다.
여기서 에이전트를 새로 스폰하거나, 끝난 에이전트를 **재활용(reuse)·정리(cleanup)** 할 수 있습니다.
(스폰·재활용은 모듈 5·6에서.)

### 6. 사용량 탭 — 토큰·비용 추적 (2분)

> 화면: 사용량 탭(UsagePage)

팀을 돌리면 토큰을 씁니다. 그 비용을 여기서 추적합니다.
실시간 사용량 + 히스토리, 모델별·일자별·에이전트별 집계,
그리고 Codex 같은 모델의 rate-limit(플랜 한도)까지 보입니다.

핵심 메시지는 **"비용은 측정되는 순간 통제된다"** — 자세한 최적화는 모듈 6에서.

### 7. 워크트리 탭 — 에이전트별 격리 작업 공간 (3분)

> 화면: 워크트리 탭(WorktreeTab) — 상태 pill 목록

마블로의 안전장치입니다.
**에이전트마다 별도의 git 워크트리**에서 일하기 때문에,
여러 에이전트가 동시에 코드를 고쳐도 서로 충돌하지 않습니다.

각 워크트리에는 상태 pill이 붙습니다:

- 🟢 mergeable — main에 깔끔히 머지 가능
- 🟡 behind — main이 앞서감(Rebase 필요)
- ⚠️ stale — 오래 방치됨
- 🔴 conflict — 충돌 발생(Resolve 필요)
- ⚪ idle — 작업 없음

여기서 Rebase / Merge를 직접 누릅니다. **머지 권한은 끝까지 PM인 여러분이 쥡니다.**
(워크트리 머지는 모듈 3·4·7에서 실전으로.)

### 8. 하네스 탭 — 스킬·MCP·CLI 원클릭 설치 (2분)

> 화면: 하네스 탭(HarnessStore)

마블로가 필요로 하는 패키지를 **버튼 한 번**으로 설치하는 스토어입니다.
필수(TaskForce 스킬·Marblo MCP), 추천(Superpowers), CLI, MCP 카테고리로 나뉘고,
설치 상태 아이콘과 설치 방식(git/mcp/npm-global/shell)이 표시됩니다.
단축키는 **⌘⇧H (Cmd/Ctrl + Shift + H)**.

수동 `npm i -g …`와 `~/.claude.json` 편집은 이제 안 해도 됩니다.
(설치 절차는 모듈 2에서.)

### 9. 설정 탭 — BYOK·프로필·프라이버시·언어 (2분)

> 화면: 설정 탭(SettingsPage)

Profile / Models / Billing / Team / **API Keys(BYOK)** / Privacy / Language.
내 API 키(Anthropic·OpenAI·Google)를 암호화 저장하고,
텔레메트리 동의와 표시 언어를 처음 한 번 맞춥니다.
(설정은 모듈 2에서.)

### 화면 하단 — 오케스트레이터 PTY 패널 (2분)

> 화면: 화면 하단 — 오케스트레이터 터미널 패널

탭이 무엇이든, **화면 아래쪽에는 오케스트레이터 터미널(PTY 패널)**이 항상 깔려 있습니다.
경계선을 드래그해 높이를 조절할 수 있어요.

여기가 여러분이 팀에게 명령하는 입구입니다.
"할 일 웹앱 만들어줘" 같은 자연어를 던지거나, `/`를 눌러 슬래시 메뉴를 띄웁니다.

마블로의 핵심 기술은 이 패널 뒤에 있습니다 — **STDIN 자동 프롬프트 주입**.
앱이 에이전트의 표준입력에 프롬프트를 직접 꽂아 넣어,
터미널을 일일이 열고 복붙하지 않아도 여러 에이전트를 프로그래밍적으로 제어합니다.
오케스트레이터가 자연어를 받아 태스크를 분해하고, 새 에이전트를 스폰하고,
각 에이전트에 초기 프롬프트를 자동 주입하는 거죠.

> 화면: 오케 패널에서 `/` 입력 → 슬래시 메뉴 팝업

`/`를 누르면 `/tf-start`, `/tf-analyze`, `/tf-review` 같은 명령이 팝업으로 뜹니다.
MCP 도구 이름(`create_tasks_bulk`, `spawn_agent` 등)을 외울 필요가 없습니다.
방향키로 고르고 Enter — 그러면 미리 정의된 한국어 프롬프트가 STDIN에 주입됩니다.

## 정리 (1분)

> 화면: 슬라이드 또는 보드 — 9탭 + 오케 PTY 한 장 요약

| 탭              | 한 줄 역할                        |
| --------------- | --------------------------------- |
| 가이드          | 막히면 돌아오는 홈 (1-3)          |
| 보드            | 칸반 — 카드가 자동으로 움직임     |
| 레인            | 에이전트별 작업대 + 터미널 attach |
| 코드            | Monaco 에디터 + diff 검토         |
| 에이전트        | 팀 대시보드 (스폰·재활용)         |
| 사용량          | 토큰·비용 추적                    |
| 워크트리        | 에이전트별 격리 + 머지            |
| 하네스          | 스킬·MCP·CLI 원클릭 설치 (⌘⇧H)    |
| 설정            | BYOK·프라이버시·언어              |
| (하단) 오케 PTY | 자연어·슬래시로 팀에 명령         |

한 문장으로: **마블로 = 칸반 보드 + 에이전트 터미널 + 워크트리가 한 화면에.**

다음 섹션에서는 9탭 중 첫 탭인 **가이드 탭**을 열어,
처음 켰을 때 스스로 길을 찾는 법을 보겠습니다.
