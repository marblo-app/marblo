# 하네스 스토어 — 스킬·MCP·CLI 원클릭 설치

> 모듈 2 · 섹션 2-1 · 약 25분
> 관련: [[1-4_큰그림_파이프라인]] | [[2-2_ClaudeCode_Codex_설치인증]]

---

## 이 레슨의 4요소

- **학습목표:** 하네스 스토어 탭에서 마블로가 요구하는 스킬·MCP·CLI 패키지를 버튼 한 번으로 설치하고, 설치 상태를 읽는다.
- **시연할 마블로 화면·기능:** 앱 설치(DMG) → 첫 실행/로그인 → 하네스 탭(HarnessStore) 전체 — Required / Recommended / MCP / CLI 카테고리, 설치 상태 배지, 버전 업데이트 체크.
- **진행할 프로젝트 단계:** 셋업(빈 맥북 0→1).
- **핵심 메시지:** "수동 `npm i -g`·`~/.claude.json` 편집은 끝. 버튼 한 번."

---

## 도입 (3분) — 수동 설치의 고통

이번 모듈은 **빈 맥북에서 0부터** 따라갑니다. 슬라이드는 거의 없고, 거의 다 실제 화면입니다.

예전 방식은 이랬어요. AI 에이전트 하나 돌리려고:

```
1. npm i -g @anthropic-ai/claude-code
2. npm i -g @openai/codex
3. ~/.claude.json 열어서 MCP 서버 블록 직접 작성
4. .mcp.json 만들어서 경로·환경변수 손으로 채우기
5. 스킬 파일 .claude/ 아래로 복사
6. 버전 안 맞으면 처음부터 다시…
```

손으로 JSON을 편집하다 콤마 하나 빠뜨리면 전부 멈춥니다. 입문자에게는 여기서부터 벽이에요.

마블로 v3는 이 전부를 **하네스 스토어**라는 탭 하나로 대체합니다. 앱스토어처럼, 필요한 걸 눌러서 설치합니다.

---

## 본문

### 1. 앱 설치 — DMG 더블클릭 (4분)

화면: 마블로 공식 사이트 다운로드 페이지

먼저 앱 자체를 깝니다. 마블로 공식 사이트에서 OS에 맞는 설치 파일을 받습니다.

```
macOS:   Marblo-x.x.x-arm64.dmg  (Apple Silicon)
         Marblo-x.x.x-x64.dmg    (Intel)
Windows: Marblo-Setup-x.x.x.exe
Linux:   Marblo-x.x.x.AppImage
```

> ⚠️ 설치 파일명·버전·다운로드 URL은 릴리스마다 바뀝니다. **촬영/실습 직전에 공식 사이트에서 현행 파일을 확인**하세요.

화면: DMG 더블클릭 → 앱 아이콘을 Applications로 드래그

macOS 기준 — DMG를 더블클릭하고, 마블로 아이콘을 `Applications` 폴더로 드래그합니다. 끝입니다. 예전 v1의 Docker 컨테이너 5개 띄우기와 비교하면 2분 vs 30분이에요.

### 2. 첫 실행 + 로그인 (3분)

화면: 마블로 첫 실행 — 로그인 화면

앱을 처음 켜면 로그인 화면이 뜹니다. Google·GitHub·이메일 중 편한 방식으로 로그인하세요. 인증은 Firebase 기반이고, 보드 카드·에이전트 상태·플로우 같은 데이터가 여기에 묶입니다.

처음 쓰는 분은 마블로가 제공하는 **공유 백엔드를 그대로** 쓰면 됩니다. 별도 설정 없이 바로 다음 단계로 갈 수 있어요. (자기만의 Firebase 프로젝트를 연결하는 고급 설정은 선택이며, 부록에서 다룹니다.)

### 3. 하네스 스토어 열기 (2분)

화면: 마블로 상단 탭바 — '하네스' 탭 클릭

상단 탭바에서 **하네스(Harness)** 탭을 엽니다. 단축키는 `⌘⇧H` (Windows/Linux는 `Ctrl+Shift+H`)예요. 어느 화면에서든 이 단축키로 바로 스토어가 열립니다.

하네스 스토어는 마블로 에이전트 군단이 돌아가는 데 필요한 모든 외부 부품 — 스킬, MCP 서버, CLI 도구 — 을 한곳에 모아둔 설치 센터입니다.

### 4. 카테고리 둘러보기 (5분)

화면: 하네스 탭 — 상단 카테고리 필터

상단에 카테고리 필터가 있습니다. 다섯 개예요.

| 카테고리        | 라벨           | 들어있는 것                                                 |
| --------------- | -------------- | ----------------------------------------------------------- |
| **Required**    | 필수 자동 설치 | TaskForce 스킬, Marblo MCP — 없으면 에이전트가 못 도는 핵심 |
| **Recommended** | 추천 스킬      | Superpowers 등 — 권장하지만 선택                            |
| **MCP**         | 유용한 MCP     | 추가 MCP 서버 (GitHub, Filesystem 등)                       |
| **CLI**         | CLI            | Claude Code, Codex 같은 CLI 도구 (→ 2-2에서 인증)           |
| **All**         | 전체           | 위를 한 화면에                                              |

각 패키지 카드에는 종류 배지가 붙습니다 — `SKILL` / `MCP` / `PLUGIN` / `CLI`. 그래서 이게 스킬인지 MCP 서버인지 한눈에 구분됩니다.

> **Required는 대부분 자동입니다.** TaskForce 스킬과 Marblo MCP는 앱이 부팅할 때 묶음으로 깔립니다(설치 방식 `bundled`). 그래서 처음 켜면 이미 "설치됨"으로 보이는 게 정상이에요.

화면: 하네스 카드 하단 — 설치 방식 라벨

각 패키지는 **설치 방식**이 라벨로 표시됩니다. 이게 마블로가 손으로 하던 일을 대신 해주는 부분이에요.

- `git` — Git 저장소를 클론해서 설치
- `mcp` — MCP 서버로 등록 (`~/.claude.json` 편집을 마블로가 대신)
- `npm-global` — `npm i -g`를 대신 실행
- `shell` — 설치 셸 스크립트 실행
- `bundled` — 앱에 미리 포함(자동)
- `manual` — 자동이 안 되는 것만, 수동 안내 제공

핵심은 — **어떤 방식이든 당신은 [설치] 버튼만 누릅니다.** `npm`이든 JSON 편집이든 마블로가 뒤에서 대신 처리해요.

### 5. 설치 상태 읽기 (4분)

화면: 하네스 카드 — 상태 배지들

패키지마다 오른쪽에 상태 배지가 있습니다. 색으로 구분돼요.

- 🟢 **설치됨** — 이미 깔림. 할 일 없음.
- ⬜ **설치** — 아직 안 깔림. 누르면 설치 시작.
- 🟡 **수동 설치** — 자동이 안 되는 패키지. 안내대로 직접 한 단계 처리.
- ⚪ **확인 중** — 마블로가 지금 설치 여부를 검사하는 중.

화면: 하네스 카드 — 버전·업데이트 표시

설치된 패키지는 버전도 같이 보여줍니다.

```
v1.2.0  (최신)              ← 최신이면 회색 '(최신)'
v1.2.0 → v1.3.0 업데이트 대기 중   ← 구버전이면 노란색으로 새 버전 안내
```

마블로가 주기적으로 최신 버전을 체크해서, 업데이트가 있으면 알려줍니다. 손으로 `npm outdated` 돌릴 필요가 없어요.

> ⚠️ **단종 예정 표시.** 더 이상 권장되지 않는 패키지에는 빨간 **단종 예정** 배지와 "단종 예정 — 설치 비권장" 문구가 붙습니다. 예를 들어 Gemini 계열이 여기에 해당합니다(자세한 건 [[2-2_ClaudeCode_Codex_설치인증]]). 이 배지가 보이면 새로 설치하지 마세요.

> **MCP 라우팅 한 가지 주의.** 하네스로 설치한 Marblo MCP는 **마블로 대시보드 안에서 스폰된 에이전트에만** 자동 연결됩니다(에이전트별 격리 설정). 외부 터미널에서 직접 띄운 CLI 세션은 사용자의 taskforce MCP 등 별도 설정으로 관리해야 합니다.

### 6. 실습 — Required 한 바퀴 (2분)

화면: 하네스 탭 — Required 카테고리

**(실습) 필수 패키지 확인·설치**

1. 하네스 탭(`⌘⇧H`)을 연다.
2. 상단에서 **Required(필수 자동 설치)** 필터를 선택한다.
3. TaskForce 스킬, Marblo MCP가 🟢 **설치됨**인지 확인한다.
4. 혹시 ⬜ **설치** 상태인 게 있으면 버튼을 눌러 설치한다.
5. **Recommended**로 필터를 바꿔 Superpowers를 설치(선택)한다.

여기까지면 에이전트가 돌 "토대"는 끝입니다. CLI 두 주역(Claude Code·Codex)은 다음 레슨에서 깔고 인증합니다.

## 정리 (2분)

화면: 체크리스트 슬라이드

설치 체크리스트:

- [ ] 마블로 앱 설치(DMG) 및 첫 실행/로그인
- [ ] 하네스 탭 열기(`⌘⇧H`)
- [ ] Required(TaskForce 스킬·Marblo MCP) = 🟢 설치됨 확인
- [ ] Recommended(Superpowers) 설치(선택)

오늘 기억할 것:

1. **하네스 스토어 = 마블로의 앱스토어.** 스킬·MCP·CLI를 버튼으로 설치.
2. **설치 방식(git/mcp/npm-global/shell/bundled/manual)은 마블로가 대신 처리.** 당신은 JSON을 편집하지 않는다.
3. **상태 배지(설치됨/설치/수동 설치/확인 중) + 버전 업데이트 체크**로 환경을 한눈에 관리.

다음 섹션에서는 멀티에이전트의 두 주역 — **Claude Code와 Codex** — 를 하네스에서 설치하고 로그인까지 끝냅니다.
