## 도입 (2분)

여러분, 축하합니다! AI YouTube 인사이트 서비스가 완성되었습니다.

화면: 칸반 보드 — 18개 카드 모두 DONE, 완료 배너

모듈 4 전체를 돌아보면:

- **4-1**: `/tf-plan`으로 PRD 작성 + 18개 태스크 설계
- **4-2**: 태스크 생성 + 4개 에이전트 스폰
- **4-3**: Sprint 1 — 백엔드 기초 (DB, 인증, YouTube, Claude API)
- **4-4**: Sprint 2 — 프론트엔드 + 병렬 처리
- **4-5**: Sprint 3 — 통합 + 테스트 + 데모
- **4-6**: 상황별 대응 패턴

이 전체 과정에서 여러분이 직접 코딩한 부분은 **없습니다**. PM으로서 기획, 관찰, 리뷰, 의사결정만 했죠.

### 아카이브 처리 (3분)

프로젝트가 완료되면 아카이브를 해둡시다:

```bash
/tf-archive
```

```
📦 Archiving project: AI YouTube 인사이트 서비스

Saved:
  ✅ Project state (18 tasks, all DONE)
  ✅ Agent activity logs
  ✅ Review/feedback history
  ✅ Generated PRD document
  ✅ Statistics snapshot

Archive location: ~/.marblo/archives/youtube-insight-20260401/

This project can be referenced later with:
  /tf-load youtube-insight-20260401
```

아카이브하면:

1. **프로젝트 상태** 전체가 저장됩니다
2. **에이전트 로그**와 **리뷰 히스토리**도 보존됩니다
3. 나중에 `/tf-load`로 불러와서 참고하거나 이어서 작업할 수 있어요

화면: 마블로 아카이브 화면

이 아카이브는 나중에 비슷한 프로젝트를 할 때 **레퍼런스**로 활용됩니다. "저번에 YouTube 서비스 만들 때 태스크를 어떻게 분해했더라?" — 이런 질문에 답해주는 거죠.

## 정리

모듈 4 전체 핵심 요약:

1. **`/tf-plan`으로 정식 기획** — PRD + 18개 태스크 + 의존성 맵 (4단계 풀세트)
2. **`/tf-create-tasks` + `/tf-spawn-agents`** — 태스크 등록과 에이전트 투입을 분리
3. **Sprint 방식 진행** — 백엔드 → 프론트엔드 → 통합 + 테스트
4. **PM의 핵심 역할** — 리뷰, 피드백, 의사결정 (코딩은 에이전트가)
5. **상황별 대응** — `/tf-fix`, `/tf-feedback`, `/tf-add`, `/tf-resume`, `/tf-hold`
6. **결과** — 68개 파일, ~5,000줄, 완전한 AI SaaS 서비스

여러분은 이제 마블로로 **처음부터 끝까지** SaaS 서비스를 만들 수 있습니다.

다음 모듈에서는 한 단계 더 나아가서 — **멀티모델 에이전트 오케스트레이션**을 다룹니다. Claude만 쓰는 게 아니라, 여러 AI 모델을 섞어서 쓰면 어떻게 되는지 알아보죠!
