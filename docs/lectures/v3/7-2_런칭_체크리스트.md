## 도입 (3분)

여러분, 랜딩페이지가 완성됐습니다. GCP Cloud Run에 배포도 해놨고요. 그러면 이제 런칭만 하면 되는 거 아닌가? 아닙니다.

화면: 슬라이드 — "코드 배포 != 런칭"

**코드 배포**와 **제품 런칭**은 완전히 다른 겁니다. 배포는 서버에 코드를 올리는 기술적 행위이고, 런칭은 사용자에게 제품을 알리고 처음 경험하게 하는 전체 프로세스입니다.

런칭 날 서버가 다운되거나, 에러가 발생하는데 모니터링이 없거나, 개인정보 처리방침이 없어서 법적 문제가 생기면 어떡하죠?

이번 섹션에서는 **런칭 전에 반드시 확인해야 할 체크리스트**를 다루고, 재밌는 건 이 체크리스트를 **마블로 에이전트 3마리가 병렬로 처리**하는 것까지 보여드리겠습니다.

## 본문 1: 기술 인프라 체크리스트 (5분)

화면: 체크리스트 슬라이드 — 기술 인프라

### 1-a: 도메인 + SSL

커스텀 도메인은 신뢰의 기본입니다. `youtube-insight.ai` 같은 깔끔한 도메인이 `marblo-todo-app-12345.run.app`보다 훨씬 전문적이죠.

```bash
# Cloud Run에 커스텀 도메인 매핑
gcloud beta run domain-mappings create \
  --service=youtube-insight-frontend \
  --domain=youtube-insight.ai \
  --region=asia-northeast3
```

화면: 도메인 등록 사이트 (Namecheap, Cloudflare 등)

**도메인 구매 팁:**

- `.ai` 도메인: AI SaaS라면 브랜딩에 좋음 (연 $50~90)
- `.com` / `.io`: 범용적이고 익숙함
- Cloudflare에서 구매하면 SSL이 자동 + DNS 관리가 편함

**SSL 설정:**

- Cloud Run은 기본적으로 HTTPS를 자동 지원합니다
- 커스텀 도메인 매핑하면 Google-managed SSL 인증서 자동 발급
- 별도 설정 불필요 — 이게 Cloud Run의 장점이에요

### 1-b: 에러 모니터링 — Sentry

화면: Sentry 대시보드 스크린샷

프로덕션에서 에러가 났는데 모르고 있다면? 사용자가 떠나죠.

```bash
# Sentry SDK 설치
npm install @sentry/nextjs
```

```bash
# Sentry 설정 마법사 실행
npx @sentry/wizard@latest -i nextjs
```

이 명령어를 실행하면 `sentry.client.config.ts`, `sentry.server.config.ts`, `sentry.edge.config.ts` 파일이 자동 생성됩니다.

```typescript
// sentry.client.config.ts
import * as Sentry from "@sentry/nextjs";

Sentry.init({
  dsn: "https://examplePublicKey@o0.ingest.sentry.io/0",
  tracesSampleRate: 1.0, // 프로덕션에서는 0.1~0.2로 낮추세요
  environment: process.env.NODE_ENV,
});
```

**Sentry에서 확인할 것들:**

- 에러 발생 시 Slack / Email 알림 설정
- Source Map 업로드 (디버깅 편의)
- Release tracking (어느 배포에서 에러가 발생했는지)

### 1-c: 분석 도구 — Analytics

화면: Google Analytics 4 대시보드

사용자가 랜딩페이지에 와서 뭘 하는지 알아야 개선할 수 있습니다.

```bash
# Google Analytics 4 연동 (gtag.js 방식)
npm install @next/third-parties
```

```tsx
// src/app/layout.tsx
import { GoogleAnalytics } from "@next/third-parties/google";

export default function RootLayout({ children }) {
  return (
    <html lang="ko">
      <body>{children}</body>
      <GoogleAnalytics gaId="G-XXXXXXXXXX" />
    </html>
  );
}
```

**추적해야 할 핵심 이벤트:**

- 랜딩페이지 조회수 (page_view)
- CTA 버튼 클릭 (sign_up)
- 가격표 섹션 도달 (scroll depth)
- 이탈 지점 (bounce rate by section)

Mixpanel이나 PostHog를 쓰면 더 세밀한 퍼널 분석이 가능합니다만, 시작은 GA4로 충분합니다.

## 본문 2: 법적 페이지 (4분)

화면: 슬라이드 — "법적 필수 페이지"

### 개인정보 처리방침 (Privacy Policy)

한국에서 서비스를 운영하면 **개인정보보호법**에 따라 개인정보 처리방침이 의무입니다. 없으면 과태료 부과 대상이에요.

포함해야 할 내용:

1. 수집하는 개인정보 항목
2. 수집 목적
3. 보유 기간
4. 제3자 제공 여부
5. 파기 방법
6. 정보주체의 권리

```
/pages/privacy.tsx  또는  /app/privacy/page.tsx
```

### 이용약관 (Terms of Service)

서비스 이용 규칙을 명시합니다:

- 서비스 이용 조건
- 환불 정책
- 면책 조항
- 분쟁 해결 방법

```
/pages/terms.tsx  또는  /app/terms/page.tsx
```

**팁:** 이 법적 문서들도 AI 에이전트에게 초안을 작성하게 할 수 있습니다. 다만 반드시 법률 전문가의 검토를 받으세요. AI가 만든 법적 문서를 그대로 쓰는 건 위험합니다.

### Footer에 링크 추가

```tsx
<footer className="bg-gray-900 text-gray-400 py-12">
  <div className="container mx-auto px-6">
    <div className="flex flex-wrap gap-8">
      <a href="/privacy" className="hover:text-white">
        개인정보 처리방침
      </a>
      <a href="/terms" className="hover:text-white">
        이용약관
      </a>
      <a href="mailto:support@youtube-insight.ai" className="hover:text-white">
        문의
      </a>
    </div>
  </div>
</footer>
```

## 본문 3: 마블로 에이전트 3마리로 병렬 처리 (5분)

화면: 마블로 앱 — 칸반 보드

자, 여기까지 체크리스트가 꽤 많죠? 이걸 사람이 하나하나 하면 반나절은 걸립니다. 마블로 에이전트를 활용해봅시다.

**(실습)** 오케스트레이터에 다음을 입력합니다:

```
런칭 준비 체크리스트를 처리해줘.

1. Sentry 에러 모니터링 설정 (Next.js + 환경변수)
2. Google Analytics 4 연동 + 핵심 이벤트 트래킹 설정
3. 개인정보 처리방침 + 이용약관 페이지 생성 (한국어, 한국법 기준)

3개 태스크를 에이전트 3마리에게 병렬로 배정해줘.
```

화면: 오케스트레이터가 태스크를 생성하고 에이전트에 배정

```
칸반 보드:
├── TASK-001: Sentry 설정        → Agent-1 (Claude)  [IN_PROGRESS]
├── TASK-002: GA4 연동            → Agent-2 (Gemini)  [IN_PROGRESS]
└── TASK-003: 법적 페이지 생성     → Agent-3 (Claude)  [IN_PROGRESS]
```

3마리가 동시에 작업합니다. Agents 탭에서 실시간으로 각 에이전트의 터미널을 전환하며 관찰할 수 있어요.

화면: Agents 탭 — 3개 에이전트 터미널 동시에 보여주기

약 5~10분 후:

```
칸반 보드:
├── TASK-001: Sentry 설정        → Agent-1  [DONE] ✓
├── TASK-002: GA4 연동            → Agent-2  [DONE] ✓
└── TASK-003: 법적 페이지 생성     → Agent-3  [DONE] ✓
```

사람이 30분 걸릴 일을 에이전트 3마리가 10분 만에 끝냈습니다. 이게 **에이전트 군단의 힘**이에요.

## 본문 4: 런칭 마케팅 전략 (3분)

화면: 슬라이드 — "런칭은 마케팅이다"

기술적 준비가 끝났으면, 이제 사람들한테 알려야 합니다.

### ProductHunt 런칭

ProductHunt는 새로운 제품을 소개하는 글로벌 플랫폼입니다:

- **타이밍**: 태평양 시간 00:01 (한국 시간 17:01)에 게시
- **준비물**: 제품 로고, 스크린샷 5장, GIF 데모, 설명문
- **핵심**: 첫 4시간의 업보트가 당일 랭킹을 결정합니다

### X (Twitter) 런칭

```
Build in public 전략:
1. 런칭 2주 전: "이런 걸 만들고 있습니다" 티저
2. 런칭 1주 전: 기능 미리보기 GIF + 대기자 명단
3. 런칭 당일: "오늘 런칭했습니다!" + ProductHunt 링크
4. 런칭 이후: 사용자 피드백 공개 반응
```

### 한국 커뮤니티

- Disquiet (디스콰이엇): 한국판 ProductHunt
- GeekNews: 기술 커뮤니티
- 카카오톡 오픈채팅: AI 개발자 커뮤니티
