★`before-login-submit-btn.png` 는 "제출 전" 이 아니라 **base 에서 제출 중에 보이는 것**이다.
base 에는 진행 상태가 없어서 제출 전과 제출 중의 화면이 같다 — 그게 이 티켓의 문제였다.

전/후를 만든 방법: 소스만 `origin/main` 으로 되돌려 `before-*` 를 찍고, 되돌린 것을 복원해
`after-*` 를 찍었다. 하네스 라우트·더미 `.env.local`·`node_modules` 심볼릭 링크는 촬영 후 전부 삭제했다.
