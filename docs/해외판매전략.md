## 1. 시장 분석

### AI 개발자 도구 시장

| 지표 | 수치 | 출처/근거 |
|------|------|----------|
| 글로벌 AI 개발자 도구 시장 규모 (2026) | ~$15B | AI DevTools + Code Assistant 시장 합산 |
| 연평균 성장률 (CAGR) | 25-30% | GitHub Copilot 유료 사용자 급증, Cursor 급성장 |
| 멀티에이전트 오케스트레이션 시장 | 초기 (< $500M) | 아직 본격적 경쟁자 부재, 선점 기회 |
| AI 코딩 어시스턴트 침투율 | ~30% (개발자 대비) | Stack Overflow 2025 Survey 기준 |

**시장 트렌드**:
- **Single Agent → Multi Agent**: GitHub Copilot, Cursor 등 단일 에이전트에서 Devin, Marblo 같은 멀티에이전트로 진화
- **Cloud → Local**: 보안/프라이버시 이유로 로컬 실행 선호 증가
- **코드 생성 → 프로젝트 관리**: 단순 코드 자동완성에서 태스크 분해/관리/리뷰까지 확장
- **BYOK (Bring Your Own Key)**: 사용자 자체 API 키 사용 모델이 신뢰 획득
- **바이브 코딩(Vibe Coding) 폭발적 성장**: Claude Code, Cursor 등으로 자연어 기반 개발이 주류로 진입

### 바이브 코딩 / Claude Code 사용량 기준 국가 분석

| 순위 | 국가 | AI 코딩 도구 채택률 | 주요 도구 | 마블로 적합도 |

### PPP (Purchasing Power Parity) 적용

Paddle의 지역 가격(Localized Pricing) 기능을 활용하여 국가별 구매력에 맞는 가격 자동 적용.

```
Paddle Price Override 설정:
├── 기본 가격: $19/mo (Pro), $39/mo (Team)
├── 미국: $19 / $39 (기준)
├── EU: €18 / €36
├── 일본: ¥2,900 / ¥5,900
├── 한국: TossPayments 별도 (19,000원 / 39,000원)
├── 인도: $9 / $19 (53% 할인)
├── 동남아: $12 / $25 (37% 할인)
├── 브라질: $12 / $25 (37% 할인)
└── 기타: $19 / $39 (기본)
```

### USP (Unique Selling Points)

1. **멀티에이전트 군단** — "혼자서도 개발팀처럼 일하세요"
   - 경쟁사: 1개 에이전트가 순차적으로 작업
   - Marblo: N개 에이전트가 병렬로 동시 작업 (각각 독립 PTY)

2. **칸반 + 에이전트 통합** — "프로젝트 관리와 AI 코딩이 하나에서"
   - 칸반 보드에서 태스크 생성 → 에이전트 자동 할당 → 진행/완료 실시간 반영

3. **Flow 에디터** — "복잡한 자동화를 노드 연결만으로"
   - 7가지 노드 타입 (Input → LLM → Agent → API → Human → Branch → Output)

4. **MCP 네이티브** — "에이전트가 프로젝트 컨텍스트를 완전히 이해"
   - MCP 서버 내장, 에이전트 간 상태 공유

5. **로컬 실행 + BYOK** — "코드가 내 머신에서만 실행"
   - 100% 로컬 실행, 사용자 자체 API 키 사용
